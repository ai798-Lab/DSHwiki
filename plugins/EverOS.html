EverOS

一份记忆，处处通用。

便携记忆层：本地优先、Markdown 原生，跨 agent 应用共用一份自进化记忆。
12,081 star v1.2.3 记忆 / 存储 GitHub ↗

安装

Python 3.12+；一个 OpenRouter API key。已知坑：混合检索需要 embedding provider，一键最简配置只能用 "method": "keyword"；Office 文档摄取依赖系统安装 LibreOffice；/api/v1 是遗留别名、将来会移除；缺可选能力时接口返回 HTTP 422；v1.2.3 起后台循环失败会 SIGTERM 退出进程，需 systemd/Docker/K8s 等外部重启机制。
Python 包：用 pip 或 uv 安装，然后运行它自带的命令。
uv pip install everos # or: pip install everos
多模态可选
uv pip install 'everos[multimodal]' # or: pip install 'everos[multimodal]'

完整使用教程

01everos demo 先跑演示（不需要 API key）
02everos init 生成 ~/.everos/everos.toml 和 ~/.everos/ome.toml
03把 OpenRouter API key 填进 everos.toml
04everos server start 启动服务，curl http://127.0.0.1:8000/health 验证
05通过 /api/v2/memory/add、/api/v2/memory/flush、/api/v2/memory/search 写入、落盘、检索记忆

config

# everos.toml [llm] model = "openai/gpt-4.1-mini" api_key = "<OPENROUTER_API_KEY>" base_url = "https://openrouter.ai/api/v1"

特色功能

·Markdown 记忆文件 + Git 版本化，本地 SQLite + LanceDB 索引，无外部数据库依赖
·关键词 + 向量混合检索，支持 user/agent/app/project/session 多维正交检索
·会话间记忆反思（reflection）自进化；可选多模态摄取（图片/PDF/音频/文档）；生态含 Claude Code 插件、EverMem Sync 等
