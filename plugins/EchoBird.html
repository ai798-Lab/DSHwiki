EchoBird

One-click installer and model switcher.

Manages installing and switching between Claude Code, Codex, dsh, and other CLIs in one place — the go-to for non-programmers.

Full tutorial

01Run the one-line install script for your platform (or download the installer manually from releases)
02Open EchoBird and install the target CLI from the tool list with one click (including DeepSeek Harness: one-click install, model switching, and launch, with a background service and browser UI)
03Configure models in one place in Model Nexus (OpenAI/Anthropic/local LLM/API routers); switching rewrites each tool's native configuration file automatically
04Use the built-in vLLM/SGLang/llama.cpp runtimes when you need a local model

Features

·Model Nexus, a unified model configuration hub: configure in one place, and it rewrites the native configuration files of 20+ tools to complete the switch
·One-click install, model switching, and launch for DeepSeek Harness (background service + browser UI), added in v5.6.5
·Built-in local LLM runtimes (vLLM/SGLang/llama.cpp) plus an AI-driven install-repair Agent
