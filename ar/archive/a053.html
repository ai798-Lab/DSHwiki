MarkTechPost：DeepSeek Harness 开发者预览版技术详解

Asif Razzaq · 2026-08-17 · 进阶
官方机制上手教程背景知识选品素材
المصدر ↗
MarkTechPost 在发布四天后写的技术盘点，是当规格说明书用的一篇。 核心信息：公式「Agent = Model + Harness」，v0.1 开发者预览、MIT 协议，插件化覆盖 models 到 UI 九大类，四种运行模式，且不锁定 DeepSeek 自家模型。 对写文章的启发：九大插件类别是画「插件版图」示意图的骨架，四种模式的准确英文名和安装命令可直接抄进上手章节。

أبرز النقاط

·核心公式 Agent = Model + Harness：dsh 定位是给开发者的基础设施，不是拿来就能用的成品
·插件化范围最全清单：models/tools/skills/sessions/sandboxes/storage/loops/scheduling/UI 九大类全部可换
·多模型服务商支持（Anthropic、OpenAI、Bedrock、Vertex、Azure）说明 dsh 不锁自家模型

أرقام أساسية

·9 大可替换插件类别：models、tools、skills、sessions、sandboxes、storage、loops、scheduling、UI
·4 种运行模式：Standard / Code Mode / Minimal / Creator Mode
·支持 6+ 模型渠道：DeepSeek、Anthropic、OpenAI、AWS Bedrock、Google Vertex、Azure 及 OpenAI 兼容端点
·v0.1 开发者预览版，MIT 协议，Python SDK 需 Python 3.10+

اقتباسات

Agent = Model + Harness
全文最核心的公式，适合做文章第一屏的概念卡或小红书封面大字
模型看到的一切都写入只增不改的会话日志，包括系统提示词、推理、工具调用及结果、子智能体调度和每一次上下文注入。
append-only 会话日志的最完整表述，讲可追溯/回放能力时引用
它明确定位是给开发者的基础设施，不是拿来就能用的成品
给读者管理预期的定调句，适合放在「什么人适合上车」小节
可替换插件涵盖 models、tools、skills、sessions、sandboxes、storage、loops、scheduling、UI 九大类
插件版图九宫格示意图的直接脚本
