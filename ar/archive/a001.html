DeepSeek Harness 官方仓库总览——5 天 15 万 star 的「一切皆插件」框架

deepseek-ai（DeepSeek 官方） · 2026-08-13 · 149,856 · 入门

المصدر ↗
DeepSeek 2026-08-13 开源的 agent harness，MIT 协议，一条命令 npx 就能在本机跑起 Web UI。核心理念「一切皆插件」：模型适配器、工具、会话存储、UI 甚至 agent 循环全部可替换，topic dsh-plugin 下 5 天冒出 6,716 个仓库。这是整篇插件推荐文的背景板：时间线、star 数、上手命令全是现成硬数字。

أبرز النقاط

·dsh 是 DeepSeek 官方 agent 框架，开源 5 天 star 逼近 15 万，插件生态靠 GitHub topic dsh-plugin 聚合
·「一切皆插件」不是口号：连 agent 循环本身都是可替换插件，这是插件生态爆发的技术前提
·官方自带中文 README、企微群和公众号入口，对中文社区异常友好
