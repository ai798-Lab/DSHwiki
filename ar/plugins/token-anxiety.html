token-anxiety

قلق التكاليف يُعالَج في مكانه.

حساب فوري للتكلفة، وأمر Explain يشرح وجهة كل token، مع مزامنة جدول الأسعار بأمر curl واحد.
0 star v0.1 التكلفة / الفوترة GitHub

التثبيت

web profile الخاص بـ DeepSeek Harness؛ وNode.js 22+. قيود معروفة (بحسب README): يحتسب مهام الجلسة الجذرية فقط، ولا تظهر جلسات subagent في الـ widget ‏(projection fold يطوي المحتوى حسب الجلسة)؛ وExplain مسار مباشر عبر host وليس دورة وكيل، فلا تدخل نتائج التحليل في سجل الجلسة وتضيع بمجرد تحديث الصفحة؛ وجدول الأسعار المدمج «مضمَّن وتنتهي صلاحيته»، ويحتاج مزامنة يدوية.
إضافة dsh: ثبّتها في الـ profile ثم أعد تشغيل dsh web لتصبح فعّالة.
من npm
dsh plugin --profile web add dsh-token-anxiety
checkout محلي
dsh plugin --profile web add /path/to/dsh-token-anxiety
npm مباشرة
npm install dsh-token-anxiety npm install dsh-token-anxiety@0.1.0
مزامنة جدول الأسعار يدويًا
curl -X POST http://127.0.0.1:3080/token-anxiety/pricing-sync -H "Content-Type: application/json" -d '{}'

دليل الاستخدام الكامل

01بعد التثبيت أعد تشغيل dsh web وحدّث الصفحة
02اعثر على widget التكلفة في منطقة إدخال المحادثة (composer band)، ثم مرّر المؤشر فوقه أو انقره لتوسيعه
03تصفّح Overview (حالة تسعير الذروة والانخفاض) وTasks (جدول قابل للفرز بتكلفة كل مهمة) وExplain (تحليل عزو بخطوة واحدة يبيّن أي المهام تستنزف المال)
04عند انتهاء صلاحية جدول الأسعار زامنه يدويًا عبر واجهة pricing-sync

config

默认货币 COP/USD/CNY（支持约 40 种，带地区格式化）；语言跟随 harness locale；价格数据经 host 侧 pricing-sync 接口刷新（curl 命令见安装区），重启后覆盖值合并进默认表。README 未给出配置文件片段原文。

الميزات

·حالة تسعير الذروة والانخفاض لحظيًا (تعرض نافذتَي peak/valley بالتوقيت المحلي)، لترى بوضوح أرخص الأوقات لتشغيل المهام
·جدول قابل للفرز بتكلفة كل مهمة، مع Explain بخطوة واحدة لعزو التكلفة (أي المهام تستنزف المال ولماذا)
·نحو 40 عملة، وسمة داكنة وأخرى فاتحة، وواجهة بالصينية والإنجليزية، وحزمة بلا اعتماديات خارجية
