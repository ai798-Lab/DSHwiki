EverOS

ذاكرة واحدة تعمل في كل مكان.

طبقة ذاكرة محمولة: محلية أولًا ومبنية على Markdown، وذاكرة واحدة ذاتية التطور تتشاركها تطبيقات الوكلاء المختلفة.
12,081 star v1.2.3 الذاكرة / التخزين GitHub ↗

التثبيت

Python 3.12+؛ ومفتاح OpenRouter API key. مطبّات معروفة: الاسترجاع الهجين يتطلب embedding provider، والتهيئة الأبسط بخطوة واحدة تقتصر على "method": "keyword"؛ واستيعاب مستندات Office يعتمد على تثبيت LibreOffice في النظام؛ و/api/v1 اسم بديل قديم سيُزال لاحقًا؛ وعند غياب قدرة اختيارية تُعيد الواجهة HTTP 422؛ ومنذ v1.2.3 يؤدي فشل الحلقة الخلفية إلى إنهاء العملية بـ SIGTERM، ما يستلزم آلية إعادة تشغيل خارجية مثل systemd أو Docker أو K8s.
حزمة Python: ثبّتها بـ pip أو uv ثم شغّل الأمر المرفق بها.
uv pip install everos # or: pip install everos
متعدد الوسائط (اختياري)
uv pip install 'everos[multimodal]' # or: pip install 'everos[multimodal]'

دليل الاستخدام الكامل

01ابدأ بـ everos demo لتشغيل العرض التجريبي (لا يحتاج API key)
02everos init لتوليد ~/.everos/everos.toml و~/.everos/ome.toml
03ضع مفتاح OpenRouter API key في everos.toml
04everos server start لتشغيل الخدمة، ثم تحقّق عبر curl http://127.0.0.1:8000/health
05اكتب الذاكرة واحفظها على القرص واسترجعها عبر /api/v2/memory/add و/api/v2/memory/flush و/api/v2/memory/search

config

# everos.toml [llm] model = "openai/gpt-4.1-mini" api_key = "<OPENROUTER_API_KEY>" base_url = "https://openrouter.ai/api/v1"

الميزات

·ملفات ذاكرة بصيغة Markdown مع إصدارات Git، وفهرسة محلية عبر SQLite وLanceDB، دون اعتماد على قاعدة بيانات خارجية
·استرجاع هجين بالكلمات المفتاحية والمتجهات، مع بحث متعامد متعدد الأبعاد على مستوى user/agent/app/project/session
·تطوّر ذاتي عبر مراجعة الذاكرة (reflection) بين الجلسات؛ واستيعاب متعدد الوسائط اختياري (صور/PDF/صوت/مستندات)؛ وتضم منظومته إضافة Claude Code وEverMem Sync وغيرهما
