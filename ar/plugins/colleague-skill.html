colleague-skill

زميلك المستقيل يعود إلى العمل رقميًا.

يحوّل وثائق زميلك السابق وأسلوبه البرمجي وعباراته المعتادة إلى skill «يعمل مثله تمامًا» — ما يسمّى الحياة الرقمية 1.0، وهو المشروع الأكثر إثارة للنقاش في المنظومة كلها.
23,139 star v0.01（Pre-release，标注 demo） skill / استنساخ المعرفة GitHub ↗

التثبيت

Python 3.9+؛ ومضيف متوافق ‏(Claude Code / OpenClaw / Codex / DeepSeek Harness وغيرها). مطبّات معروفة (بحسب README): مصدر بيانات WeChat غير مستقر حاليًا (يُنصح باستخدام أدوات مفتوحة المصدر)؛ والنسخة المجانية من Slack تتيح 90 يومًا من السجلات فقط؛ وواجهة DingTalk لا تدعم سحب الرسائل السابقة؛ والمشروع كله لا يزال beta؛ وجودة المواد تحدّد جودة الـ Skill مباشرة.
Skill: استنسخ المستودع إلى مجلد skills الخاص بالـ agent ثم أعد التشغيل.
التثبيت باللغة الطبيعية (قلها لأي agent مضيف)
Install the dot-skill skill for me: https://github.com/titanwings/colleague-skill
Claude Code على مستوى المشروع
mkdir -p .claude/skills git clone https://github.com/titanwings/colleague-skill .claude/skills/create-colleague
Claude Code على المستوى العام
git clone https://github.com/titanwings/colleague-skill ~/.claude/skills/create-colleague
OpenClaw
git clone https://github.com/titanwings/colleague-skill ~/.openclaw/workspace/skills/create-colleague
مجلدات يدوية لمضيفين آخرين: Codex ~/.codex/skills/dot-skill؛ DeepSeek Harness ~/.dsh/skills/dot-skill
التبعيات
pip3 install -r requirements.txt

دليل الاستخدام الكامل

01اكتب /create-colleague (أو /dot-skill) داخل الوكيل المضيف للبدء
02اختر عائلة الشخصية (زميل/علاقة/مشهور)، ثم أدخل الاسم المستعار والمستوى الوظيفي ووسوم الشخصية
03اختر مصدر البيانات ‏(Feishu/DingTalk/Slack/WeChat/البريد/PDF وغيرها) واستورد المواد
04بعد التوليد استدعِ هذا «الزميل الرقمي» مباشرة بالأمر /{slug}

الميزات

·ثلاث عائلات من الشخصيات: ‏colleague (زميل) / relationship (علاقة) / celebrity (مشهور)، ويأتي مسار المشاهير بسلسلة أدوات بحثية لمعالجة الترجمات النصية
·دمج بيانات من مصادر متعددة: ‏Feishu وDingTalk وSlack وWeChat والبريد الإلكتروني وملفات PDF
·الـ Skill المولَّد يدعم التحكم في الإصدارات والتراجع، ويعمل على 5 أنواع من المنصات المضيفة
