awesome-dsh-plugin

البحث عن الإضافات يبدأ من هنا.

دليل مختارات للإضافات بمراجعة بشرية للشيفرة المصدرية: نحو 800+ إضافة في 20 فئة، مع سوق الإضافات المرافق dshmarket.
7,572 star أدلة / قوائم GitHub ↗

التثبيت

DeepSeek Harness نفسه (وتُثبَّت الإضافات عبر dsh plugin add). نص معيار الإدراج: "An entry is added when the plugin installs with dsh plugin add, does what its one-line description says, sits in the right category, and is maintained. Every submission is checked against its own source before merging."
إضافة dsh: ثبّتها في الـ profile ثم أعد تشغيل dsh web لتصبح فعّالة.
لجميع الإضافات في القائمة استخدم
dsh plugin add <插件名>
سوق الإضافات المرافق (تصفح داخل التطبيق + تثبيت/ترقية بنقرة واحدة)
dsh plugin --profile web add dshmarket
مساعد البحث عن الإضافات
dsh plugin --profile web add dsh-find-plugin

دليل الاستخدام الكامل

01افتح README المستودع وتصفّح الفئات العشرين (تحسين UI/فوترة الاستهلاك/السمات/النماذج/الذاكرة/الرؤية/الصوت/سير العمل/الأمان وغيرها)
02بعد اختيار الإضافة ثبّتها عبر dsh plugin add (كل إضافة تعلن dsh.bundle manifest)
03أو ثبّت dshmarket أولًا لتثبيت الإضافات وترقيتها وتبديل السمات بخطوة واحدة من المتصفح داخل تطبيق dsh
04للمساهمة: افتح PR واتبع قائمة المراجعة في contributing.md

الميزات

·فهرسة شاملة لنحو 800+ إضافة ضمن 20 فئة ‏(UI/الفوترة/السمات/النماذج/الجلسات/الذاكرة/الأدوات/الرؤية/الصوت/skills/الأمان/التحكم عن بُعد وغيرها)
·تحقّق يدوي لكل مدخل مقابل الشيفرة المصدرية قبل الإدراج؛ وتُحذف المستودعات التي تختفي أو يتوقف صيانتها أو تتعطّل إضافتها (الإدراج ليس دائمًا)
·يرافقه سوق الإضافات dshmarket ومساعد dsh-find-plugin، ليشكّلا معًا بوابة توزيع الإضافات
