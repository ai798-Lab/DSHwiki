OpenViking

قاعدة بيانات سياق للوكلاء من Volcengine.

إدارة موحّدة للذاكرة ومعرفة RAG والـ Skills، مع استرجاع ثلاثي الطبقات L0/L1/L2 يوفّر الـ token، وبدعم من شركة كبرى.
28,891 star v0.4.14 الذاكرة / التخزين GitHub ↗

التثبيت

Python 3.10+. تنبيه بشأن الترخيص: المشروع الأساسي تحت AGPLv3، أما الـ CLI وexamples فتحت Apache 2.0.
حزمة Python: ثبّتها بـ pip أو uv ثم شغّل الأمر المرفق بها.
pip install openviking --upgrade
openviking-server init # 交互式配置向导 openviking-server doctor # 校验配置 openviking-server # 启动服务
VikingBot اختياري
pip install "openviking[bot]" openviking-server --with-bot ov chat

دليل الاستخدام الكامل

01شغّل openviking-server init لبدء المعالج التفاعلي (لتهيئة providers مثل Volcengine/OpenAI/Kimi/GLM/Ollama)
02openviking-server doctor للتحقق من التهيئة
03openviking-server لتشغيل الخدمة
04أدر المحتوى وابحث فيه عبر ov CLI: ‏ov status، ‏ov add-resource https://github.com/volcengine/OpenViking، ‏ov ls viking://resources/، ‏ov find "what is openviking"
05الربط بالوكلاء: يدعم Claude Code وCodex وCursor وعملاء MCP وLangChain/LangGraph وغيرها

config

配置文件位置：~/.openviking/ov.conf（由 init 向导生成）。README 未给出配置文件内容原文片段。

الميزات

·تحميل المحتوى على ثلاث طبقات: L0 (ملخّص) / L1 (نظرة عامة) / L2 (تفاصيل)، مع توسيع عند الطلب لتوفير الـ token
·عملية الاسترجاع قابلة للمراقبة: يحتفظ بمسار تصفّح الأدلة لتسهيل التنقيح والتدقيق
·بعد إنهاء الجلسة يحوّل تلقائيًا تفضيلات المستخدم وخبرة الوكيل إلى ذاكرة طويلة الأمد
