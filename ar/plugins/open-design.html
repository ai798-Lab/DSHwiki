open-design

اجعل dsh محرّك التصميم الخاص بك.

نسخة مفتوحة المصدر من Claude Design، تطبيق سطح مكتب يعمل محليًا أولًا. بعد ربطه بـ dsh تتحول تعديلاتك النصية إلى صور لحظيًا، وهو أكبر مشروع في المنظومة.
88,304 star open-design-v0.19.2 التصميم / تطبيق سطح مكتب GitHub

التثبيت

نسخة سطح المكتب بلا اعتماديات؛ أما التشغيل من المصدر أو Docker فيحتاج Node ‏~24 وpnpm 10.33.x، إضافة إلى CLI لوكيل برمجة. مطبّات معروفة: على macOS/WSL2 يحجب أمر النظام od ‏(octal-dump) أمر od الخاص بـ Open Design، ويلجأ مستخدمو سطح المكتب بدلًا منه إلى مقطع Settings → MCP server؛ وعناوين IP الداخلية ‏(RFC1918/link-local/CGNAT/metadata السحابية) تحجبها طبقة الوكيل افتراضيًا بحماية SSRF، ويلزم السماح بها صراحةً عبر OD_ALLOWED_INTERNAL_HOSTS.
حزمة npm: ثبّتها عالميًا مرة واحدة، أو شغّلها عبر npx دون تثبيت.
تطبيق سطح المكتب (موصى به): نزّل حزمة التثبيت لـ macOS/Windows/Linux(AppImage) من open-design.ai أو GitHub ReleasesWindowsmacOSLinux
od mcp install <agent> # <agent> = claude | codex | reasonix | raven | cursor | copilot | openclaw | antigravity | pi | vibe | hermes | cline | kimi | kiro | trae | opencode
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>
خاص بـ DeepSeek Harness (ثبّت أولًا dsh CLI الرسمي)
od agent setup deepseek-harness
Docker
git clone https://github.com/nexu-io/open-design.git cd open-design/deploy cp .env.example .env echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env docker compose up -d # open http://127.0.0.1:7456
التشغيل من المصدر
git clone https://github.com/nexu-io/open-design.git cd open-design corepack enable && pnpm install pnpm tools-dev run web

دليل الاستخدام الكامل

01تنزيل تطبيق سطح المكتب وتثبيته (بلا تهيئة، ويكتشف وكلاء البرمجة المثبّتين تلقائيًا)
02افتح التطبيق ليحمّل تلقائيًا أكثر من 100 skill و151 نظام تصميم وقوالب العرض
03أدخل الـ brief: اختر نوع المُخرَج، ثم اكتب الوصف، ثم اختر نظام التصميم والنموذج
04تابع الوكيل وهو يولّد المحتوى تدفقيًا في نافذة المعاينة
05صدّر بصيغة HTML / PDF / PPTX / MP4 / ZIP

config

OD_ALLOWED_INTERNAL_HOSTS=<host1>,<host2>,... # 逗号或空白分隔的裸主机名/IP；IPv6 需加方括号如 [fd00::1]

الميزات

·يدعم ربط 27 وكيل برمجة ‏(Claude Code / Codex / Cursor / dsh وغيرها) بأسلوب BYOK
·يتضمّن 151 نظام تصميم بمستوى العلامات التجارية، وأكثر من 100 skill وظيفي، و277 إضافة
·محلي أولًا، ويُخرج ملفات حقيقية، مع دعم التصدير بصيغ HTML/PDF/PPTX/MP4
