dsh-web-ui

امنح dsh وجهًا.

حزمة إضافات Web UI متكاملة: لوحة مهام، ومخطط Git، وتحكّم عن بُعد من الهاتف، ومركز سمات — إن أردت واجهة رسومية فثبّت هذه.
4,097 star v0.1.20 UI GitHub

التثبيت

أن يكون dsh مثبّتًا وأن يعمل dsh web بشكل سليم (لا متطلبات إضافية لمسار npm)؛ أما التثبيت من المستودع فيحتاج Node.js ≥ 22 وpnpm. مطبّات معروفة (بحسب README): عتبة release-age في pnpm 11 تُثبّت إصدارًا قديمًا بدل إصدارات @linxin666/* الصادرة خلال 10 أيام، فيظهر عند تطبيق السمة الخطأ ERR_MODULE_NOT_FOUND ... dsh-client-ui-skin-* (استثنِها بالتهيئة الواردة أعلاه)؛ وكلمات مرور SSH وعباراتها السرية تُخزَّن كنص صريح في ~/.dsh/dsh-ssh.json ‏(0600)، وقد تُعيد إعادة الاتصال تنفيذ أوامر غير مُتكرّرة الأثر، كما أن المخرجات البعيدة غير مُنقّاة؛ وCloudflare quick tunnel وTailscale Serve لا يدعمان SSE، فيتراجع الهاتف تلقائيًا إلى الاستقصاء وقد تتأخر الرسائل بضع ثوانٍ؛ والمهام المجدولة التي تفوت أثناء توقف المضيف أو سُباته تُتخطّى ولا تُشغَّل لاحقًا.
إضافة dsh: ثبّتها في الـ profile ثم أعد تشغيل dsh web لتصبح فعّالة.
الحزمة الكاملة (موصى به)
dsh plugin --profile web add @linxin666/dsh-web-ui-all
تثبيت السمة فقط
dsh plugin --profile web add @linxin666/dsh-skins
تثبيت مفرد
dsh plugin --profile web add @linxin666/dsh-liangshen dsh plugin --profile web add @linxin666/dsh-client-ui-task-board dsh plugin --profile web add @linxin666/dsh-ssh dsh plugin --profile web add @linxin666/dsh-tool-describe-image dsh plugin --profile web add @linxin666/dsh-pet dsh plugin --profile web add dsh-better-sidebar
التثبيت من المستودع (تطوير/تصحيح)
git clone https://github.com/zhu1090093659/dsh-web-ui.git cd dsh-web-ui pnpm install pnpm -r build node scripts/link-profile.mjs dsh plugin --profile web add link:$(pwd)/packages/dsh-web-ui-all dsh web
إلغاء التثبيت
dsh plugin --profile web remove @linxin666/dsh-web-ui-all

دليل الاستخدام الكامل

01ثبّت الحزمة المجمّعة @linxin666/dsh-web-ui-all بالأمر المُوصى به
02أعد تشغيل dsh web لتظهر مداخل الإضافات في الشريط الجانبي
03من Settings → Plugin Configuration فعّل الإضافات أو عطّلها، أو ادخل مركز السمات لتجربة 11 سمة (عاين أولًا ثم طبّق)

config

# 修复 pnpm 11 新版扣发导致的皮肤崩溃：profile 的 pnpm-workspace.yaml 加 minimumReleaseAgeExclude: - '@linxin666/*' # 以及 nodeLinker: hoisted

·لوحة مهام بجدولة زمنية عبر cron؛ ومخطط مسارات بصري لفروع Git
·اقتران بمسح رمز من الهاتف للتحكم عن بُعد، ولوحة عمليات SSH؛ وأداة لفهم الصور موصولة بواجهة رؤية
·تميمة الحوت قابلة للتخصيص، وإحصاء token لحظي، و11 سمة تُجرَّب وتُبدَّل فورًا، مع agent preset مُحسَّن لـ DeepSeek V4 Pro
