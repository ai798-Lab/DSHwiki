คู่มือใช้งานฉบับเต็ม

01รันสคริปต์ติดตั้งบรรทัดเดียวของแพลตฟอร์มนั้น ๆ (หรือดาวน์โหลดตัวติดตั้งเองจากหน้า releases)
02เปิด EchoBird แล้วติดตั้ง CLI ที่ต้องการด้วยคลิกเดียวจากรายการเครื่องมือ (รวมถึง DeepSeek Harness: ติดตั้ง + สลับโมเดล + เปิดใช้งานด้วยคลิกเดียว, เซอร์วิสเบื้องหลัง + UI บนเบราว์เซอร์)
03ตั้งค่าโมเดลแบบรวมศูนย์ใน Model Nexus (OpenAI/Anthropic/LLM ในเครื่อง/ตัวจัดเส้นทาง API) เวลาสลับ ระบบจะเขียนทับไฟล์ตั้งค่าเนทีฟของแต่ละเครื่องมือให้เอง
04ถ้าต้องใช้โมเดลในเครื่อง ให้ใช้รันไทม์ vLLM/SGLang/llama.cpp ที่มีมาให้

คุณสมบัติ

·Model Nexus ศูนย์กลางตั้งค่าโมเดลแบบรวมศูนย์: ตั้งที่เดียว ระบบจะเขียนทับไฟล์ตั้งค่าเนทีฟของเครื่องมือ 20+ ตัวให้สลับตาม
·ติดตั้ง DeepSeek Harness + สลับโมเดล + เปิดใช้งาน ด้วยคลิกเดียว (เซอร์วิสเบื้องหลัง + UI บนเบราว์เซอร์) เพิ่มเข้ามาใน v5.6.5
·มีรันไทม์ LLM ในเครื่องมาให้ (vLLM/SGLang/llama.cpp) + Agent ซ่อมการติดตั้งที่ขับเคลื่อนด้วย AI

EchoBird 是一个开源桌面工具，专门把 AI Agent 的部署门槛往下压。 它主打三个“一键”：安装 Claude Code / OpenClaw 等 Agent、给不同 Agent 切换模型、在本地部署 GGUF / HuggingFace 模型。Windows、macOS、Linux 都有包，MIT 免费。 适合已经在用 Codex、Cursor、Claude
EchoBird เป็นเครื่องมือเดสก์ท็อปโอเพนซอร์สที่ตั้งใจกดกำแพงการติดตั้งใช้งาน AI Agent ให้ต่ำลง มันชูสาม “คลิกเดียว”: ติดตั้ง Agent อย่าง Claude Code / OpenClaw, สลับโมเดลให้ Agent แต่ละตัว และติดตั้งโมเดล GGUF / HuggingFace ในเครื่อง มีแพ็กเกจครบทั้ง Windows, macOS, Linux ใช้ฟรีภายใต้ MIT เหมาะกับคนที่ใช้ Codex, Cursor, Claude อยู่แล้ว (โพสต์ถูกตัดที่ต้นทาง)
