OpenViking

ฐานข้อมูลบริบทสำหรับ Agent จาก Volcengine

จัดการทั้งความจำ, RAG ความรู้ และ Skills ไว้ที่เดียว ค้นแบบสามชั้น L0/L1/L2 ช่วยประหยัด token พร้อมแบ็กอัพจากบริษัทใหญ่
28,891 star v0.4.14 ความจำ / จัดเก็บข้อมูล GitHub ↗

การติดตั้ง

Python 3.10+ ข้อควรทราบเรื่องไลเซนส์: โปรเจกต์หลักเป็น AGPLv3 ส่วน CLI และ examples เป็น Apache 2.0
แพ็กเกจ Python: ติดตั้งด้วย pip หรือ uv แล้วรันคำสั่งที่มากับแพ็กเกจ
pip install openviking --upgrade
openviking-server init # 交互式配置向导 openviking-server doctor # 校验配置 openviking-server # 启动服务
VikingBot (ตัวเลือกเสริม)
pip install "openviking[bot]" openviking-server --with-bot ov chat

คู่มือใช้งานฉบับเต็ม

01openviking-server init เพื่อรันตัวช่วยตั้งค่าแบบโต้ตอบ (ตั้งค่า provider อย่าง Volcengine/OpenAI/Kimi/GLM/Ollama)
02openviking-server doctor เพื่อตรวจความถูกต้องของการตั้งค่า
03openviking-server เพื่อเริ่มเซอร์วิส
04ใช้ ov CLI จัดการและค้นหา: ov status, ov add-resource https://github.com/volcengine/OpenViking, ov ls viking://resources/, ov find "what is openviking"
05เชื่อมเข้ากับ agent: รองรับ Claude Code, Codex, Cursor, ไคลเอนต์ MCP, LangChain/LangGraph ฯลฯ

config

配置文件位置：~/.openviking/ov.conf（由 init 向导生成）。README 未给出配置文件内容原文片段。

คุณสมบัติ

·โหลดเนื้อหาเป็นชั้นสามระดับ L0 (สรุป) / L1 (ภาพรวม) / L2 (รายละเอียด) กางเฉพาะที่ต้องใช้เพื่อประหยัด token
·ตรวจสอบกระบวนการค้นหาได้: เก็บร่องรอยการไล่ดูไดเรกทอรีไว้ ทำให้ดีบักและตรวจสอบย้อนหลังได้สะดวก
·หลังปิดเซสชัน ระบบจะบันทึกความชอบของผู้ใช้และประสบการณ์ของ agent เป็นหน่วยความจำระยะยาวอัตโนมัติ
