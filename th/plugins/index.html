วิธีติดตั้งปลั๊กอิน dsh

ปลั๊กอินเนทีฟของ dsh ติดตั้งลง profile ด้วยคำสั่งเดียว แล้วรีสตาร์ท dsh web จึงจะมีผล:
dsh plugin --profile web add <plugin>
คัดลอก
รายการด้านล่างหลายตัวไม่ใช่ปลั๊กอินเนทีฟของ dsh แต่เป็นเครื่องมือแยกต่างหาก เช่น แพ็กเกจ npm แพ็กเกจ Python แอปเดสก์ท็อป หรือ preset ที่ต้องคัดลอกลงโฟลเดอร์ วิธีติดตั้งต่างกันไป เปิดหน้าของแต่ละปลั๊กอินเพื่อดูคำสั่งเต็มแยกตามระบบปฏิบัติการ
dsh-anchored-standard 3,423 star

เริ่มด้วยโหมดมินิมอล แล้วปล่อยของเต็มกำลัง

preset สองจังหวะ: ช่วงแรกใช้โหมดมินิมอลเพื่อกดสัญญาณรบกวน แล้วสลับไปใช้ชุดเครื่องมือมาตรฐานเต็มรูปแบบกลางทาง การทดลองเทียบผลของชุมชนดันคะแนน benchmark จาก 91 ขึ้นเป็น 98 หมายเหตุ: ผู้เขียนหยุดพัฒนาต่อแล้ว
dsh_home="${DSH_HOME:-$HOME/.dsh}"
