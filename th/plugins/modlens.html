modlens

เปิดตาให้โมเดลที่อ่านได้แต่ตัวอักษร

ปลั๊กอินด้านภาพตัวแรกของ dsh: วางรูปลงไป แล้วได้หลักฐานเป็น JSON แบบมีโครงสร้างกลับมาทันที พร้อมระบบสำรอง 10 เอนจิน
2,789 star v3.18.3 ภาพ / มัลติโมดัล GitHub ↗

การติดตั้ง

เลือกอย่างใดอย่างหนึ่งจากสามทาง: Claude Code/Codex/OpenCode/Pi ที่ล็อกอินไว้แล้ว (ใช้เครดิเชียลเดิมซ้ำ), Gemini API key แบบฟรี (Google AI Studio) หรือ Antigravity CLI แบบฟรี จุดที่ต้องระวัง: คำสั่งติดตั้งตรึงไว้ที่ @3.18.3 แทน @latest โดยตั้งใจ เพราะ pnpm 11 จะกันเวอร์ชันใหม่ที่ออกมาไม่เกิน 24 ชั่วโมงไว้; โมเดลที่มองภาพได้จะถูกคัดออกอัตโนมัติ ระบบจะครอบชั้นวิชวลให้เฉพาะโมเดลข้อความล้วน; โมเดลที่ยืนยันไม่ได้จะปล่อยไว้ตามเดิมเพื่อคงพฤติกรรมการแปะรูปแบบเนทีฟ
ปลั๊กอิน dsh: ติดตั้งลงใน profile แล้วรีสตาร์ท dsh web จึงจะมีผล
DeepSeek Harness (ตรึงเลขเวอร์ชันไว้โดยตั้งใจ ดูหัวข้อข้อควรระวัง)
npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.18.3
สาย LIUSTACK skills
npx -y skills add liustack/vibemaster -g
ติดตั้งด้วยภาษาธรรมชาติ: ส่งประโยคนี้ให้ AI ของคุณ
Install and configure the modlens skill following https://github.com/liustack/modlens/blob/main/INSTALL.md, then run the health check

คู่มือใช้งานฉบับเต็ม

01ส่งคำสั่งติดตั้งบรรทัดนั้นใน INSTALL.md ให้ agent ของคุณตรง ๆ แล้วให้มันติดตั้งเองพร้อมรัน health check
02ถ้า health check ว่างเปล่า ให้ตั้งเอนจินฟรีสักหนึ่งทาง (แนะนำ Gemini API key ใช้เวลา 3 นาที ไม่ต้องใช้บัตรเครดิต)
03ติดตั้งเสร็จก็คุยได้เลย: วางรูปหรือโยนพาธเข้าไป ถามอะไรก็ได้ skill จะทำงานเอง (หรือเข้าผ่านตัวเลือกโมเดล「(modlens vision)」)

config

modlens config set openai.baseUrl https://dashscope.aliyuncs.com/compatible-mode/v1 modlens config set openai.apiKey <key> modlens config set openai.model qwen3-vl-plus # 其他常用项 modlens config set provider <name> modlens config set proxy <url> modlens config set reuse.codex true modlens config set reuse.opencode true modlens config set reuse.pi true modlens config set reuse.grok true

คุณสมบัติ

·เอนจินวิชวล 10 ทาง (provider ในตัว 6 ตัว + local agent CLI ที่นำมาใช้ซ้ำได้ 4 ตัว) ต่อกันเป็นสายสำรองที่สลับเองอัตโนมัติเมื่อล้มเหลว
·ใช้เครดิเชียลมัลติโมดัลที่มีอยู่ซ้ำได้โดยไม่ต้องตั้งค่า: ไม่มี hooks ไม่มี wrapper ไม่มีโปรเซสพร็อกซีในเครื่อง และไม่แก้ไฟล์ตั้งค่าใด ๆ ของ harness
·ทูล modlens_read_image แบบเนทีฟคืนค่าเป็น JSON ที่มีโครงสร้าง ประกอบด้วยข้อความถอดครบทั้งหน้า การแบ่งโซนเลย์เอาต์ตามลำดับการอ่าน และรายการเอนทิตีกับความสัมพันธ์
