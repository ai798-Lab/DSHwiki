token-anxiety

ความกังวลเรื่องค่าใช้จ่าย คลายได้ทันที

คำนวณค่าใช้จ่ายแบบเรียลไทม์ คำสั่ง Explain อธิบายว่า token ทุกก้อนหายไปไหน ตารางราคาซิงก์ได้ด้วย curl คำสั่งเดียว
0 star v0.1 ต้นทุน / การคิดเงิน GitHub ↗

การติดตั้ง

ต้องใช้ web profile ของ DeepSeek Harness; Node.js 22+ ข้อจำกัดที่ทราบ (ตามที่ README เขียนไว้เอง): นับเฉพาะงานของเซสชันหลัก เซสชันของ subagent จะไม่โผล่ใน widget (projection fold ยุบตามเซสชัน); Explain เป็นเส้นทางที่ต่อตรงกับ host ไม่ใช่รอบการทำงานของ agent ผลวิเคราะห์จึงไม่เข้าล็อกเซสชันและหายทันทีเมื่อรีเฟรชหน้า; ตารางราคาที่มีมาในตัวเป็น「ของที่ฝังไว้และจะหมดอายุ」ต้องซิงก์เอง
ปลั๊กอิน dsh: ติดตั้งลงใน profile แล้วรีสตาร์ท dsh web จึงจะมีผล
จาก npm
dsh plugin --profile web add dsh-token-anxiety
เช็กเอาต์ในเครื่อง
dsh plugin --profile web add /path/to/dsh-token-anxiety
ใช้ npm โดยตรง
npm install dsh-token-anxiety npm install dsh-token-anxiety@0.1.0
ซิงก์ตารางราคาด้วยตนเอง
curl -X POST http://127.0.0.1:3080/token-anxiety/pricing-sync -H "Content-Type: application/json" -d '{}'

คู่มือใช้งานฉบับเต็ม

01ติดตั้งเสร็จให้รีสตาร์ท dsh web แล้วรีเฟรชหน้าเว็บ
02หา widget ต้นทุนในแถบพิมพ์ข้อความ (composer band) แล้ว hover หรือคลิกเพื่อกางออก
03ดู Overview (สถานะราคาช่วงพีค/ช่วงถูก), Tasks (ตารางต้นทุนรายงานที่เรียงลำดับได้), Explain (คลิกเดียววิเคราะห์ว่างานไหนกำลังเผาเงิน)
04เมื่อตารางราคาหมดอายุ ให้ซิงก์เองผ่านอินเทอร์เฟซ pricing-sync

config

默认货币 COP/USD/CNY（支持约 40 种，带地区格式化）；语言跟随 harness locale；价格数据经 host 侧 pricing-sync 接口刷新（curl 命令见安装区），重启后覆盖值合并进默认表。README 未给出配置文件片段原文。

คุณสมบัติ

·สถานะราคาช่วงพีค/ช่วงถูกแบบเรียลไทม์ (แสดงหน้าต่าง peak/valley ตามโซนเวลาของเครื่อง) เห็นชัดว่าช่วงไหนรันงานแล้วถูกกว่า
·ตารางต้นทุนรายงานที่เรียงลำดับได้ + ปุ่ม Explain คลิกเดียวเพื่อหาสาเหตุ (งานไหนกินเงินและเพราะอะไร)
·รองรับราว 40 สกุลเงิน, ธีมสว่าง/มืด, สองภาษาจีน-อังกฤษ และแพ็กมาโดยไม่พึ่งดีเพนเดนซีภายนอกเลย
