smooth-stream

ปลั๊กอินสตรีมข้อความจากชุมชนจีน

ปรับ preset ได้สามระดับผ่าน cordis.patch.yml จำนวน star ไม่มาก แต่กระแสในวงคนจีนไม่น้อย
21 star ประสบการณ์ใช้งาน / การแสดงผล GitHub ↗

การติดตั้ง

ต้องมีรีโปซอร์สโค้ดของ DeepSeek Harness หรือมี dsh อยู่ใน PATH; และต้องมี pnpm พฤติกรรม/จุดที่ต้องระวัง: ถ้าระบบเปิด prefers-reduced-motion ไว้ ข้อความจะแสดงทั้งก้อนทันทีโดยไม่มีอนิเมชัน; ถ้าเฟรมเรตต่ำกว่า 30fps และคำตอบไม่ได้อยู่ในวิวพอร์ต การค่อย ๆ ปรากฏจะหยุดชั่วคราวแล้วไปต่อเมื่อกลับมา; ระหว่างสตรีม การเปิดปิดบล็อกความคิดด้วยมือมีสิทธิ์เหนือกว่าการกางอัตโนมัติ; เมื่อติดตั้งแบบ link:/file: สำหรับพัฒนาในเครื่อง ปุ่มอัปเดตจะถูกปิดใช้งาน
ปลั๊กอิน dsh: ติดตั้งลงใน profile แล้วรีสตาร์ท dsh web จึงจะมีผล
pnpm dsh plugin --profile web add dsh-smooth-stream
เมื่อ dsh อยู่ใน PATH
dsh plugin --profile web add dsh-smooth-stream
เริ่มใช้งาน
pnpm dsh web
อัปเดต
dsh plugin --profile web update dsh-smooth-stream
ถอนการติดตั้ง
pnpm dsh plugin --profile web remove dsh-smooth-stream
อีกรูปแบบหนึ่งจากโพสต์เปิดตัวบน Reddit (ติดตั้งตรงผ่านโปรโตคอล github:)
pnpm dsh plugin --profile web add github:Laplace-bit/dsh-smooth-stream

คู่มือใช้งานฉบับเต็ม

01รันคำสั่งติดตั้งในไดเรกทอรีซอร์สโค้ดของ dsh (หรือที่ไหนก็ได้ถ้ามี dsh อยู่ใน PATH)
02pnpm dsh web เพื่อเปิดหน้าอินเทอร์เฟซ
03ดูล็อกของ Host ถ้าขึ้น "[dsh-smooth-stream] plugin loaded!" แปลว่าติดตั้งเรียบร้อย
04ปรับพารามิเตอร์ได้ที่ Settings → Plugins → Plugin Configuration

config

在 profile 的 cordis.patch.yml 里改 preset 值：realtime（贴近模型到达速率）/ balanced（默认）/ silky（大缓冲、慢追赶）；另有 maxScrollSpeedPxPerSec（默认 1000）限制滚动速度上限。README 未给出完整 yml 片段原文。

คุณสมบัติ

·ค่อย ๆ แสดงข้อความตามจังหวะที่โมเดลพ่นตัวอักษรออกมา ไม่ทิ้งลงมาทั้งก้อนแบบกระโชก และคงรูปแบบ Markdown ไว้ตลอด
·บรรทัดใหม่เลื่อนเข้ามาในวิวพอร์ตแทนที่จะดันเนื้อหาเดิมออกไป; เมื่อผู้ใช้เลื่อนขึ้น ระบบจะเคารพตำแหน่งการเลื่อนและไม่แย่งโฟกัส
·กางกระบวนการคิดให้อัตโนมัติ (เวอร์ชันใหม่แสดง deep diving ค้างไว้ตลอด) พร้อมรองรับการลดระดับสำหรับ reduced-motion และเฟรมเรตต่ำ
