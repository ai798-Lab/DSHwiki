colleague-skill

離職同事，數位回聘。

把前輩的文件、程式碼風格和口頭禪做成“會像本人一樣做事”的 Skill——所謂數位生命 1.0，全生態系話題度最高的專案。
23,139 star v0.01（Pre-release，标注 demo） skill / 知識復刻 GitHub ↗

安裝

Python 3.9+；一個相容的宿主（Claude Code / OpenClaw / Codex / DeepSeek Harness 等）。已知地雷（README 自述）：微信資料來源目前不穩定（建議改用開源工具）；Slack 免費版只能取得 90 天紀錄；釘釘 API 不支援拉取歷史訊息；整體仍是 beta；素材品質直接決定 Skill 品質。
Skill：把儲存庫複製到宿主 agent 的 skills 目錄，重啟後即可呼叫。
自然語言安裝（對任一宿主 agent 說）
Install the dot-skill skill for me: https://github.com/titanwings/colleague-skill
Claude Code 專案層級
mkdir -p .claude/skills git clone https://github.com/titanwings/colleague-skill .claude/skills/create-colleague
Claude Code 全域
git clone https://github.com/titanwings/colleague-skill ~/.claude/skills/create-colleague
OpenClaw
git clone https://github.com/titanwings/colleague-skill ~/.openclaw/workspace/skills/create-colleague
其他宿主手動目錄：Codex ~/.codex/skills/dot-skill；DeepSeek Harness ~/.dsh/skills/dot-skill
相依套件
pip3 install -r requirements.txt

完整使用教學

01在宿主 agent 裡輸入 /create-colleague（或 /dot-skill）啟動
02選角色族（同事/關係/名人），輸入別名、公司層級、性格標籤
03選擇資料來源（飛書/釘釘/Slack/微信/Email/PDF 等）匯入資料
04產生後用 /{slug} 指令直接呼叫這個“數位同事”

特色功能

·三大角色族：colleague（同事）/ relationship（關係）/ celebrity（名人），名人線另配字幕處理研究工具鏈
·多來源資料整合：飛書、釘釘、Slack、微信、Email、PDF
·產生的 Skill 支援版本控制與回滾，跨 5 類宿主平台通用
