open-design

把 dsh 當成你的設計引擎。

開源版 Claude Design，本地優先的桌面應用程式。接上 dsh 之後，文字改稿即時出圖，是生態系裡最大的專案。
88,304 star open-design-v0.19.2 設計 / 桌面應用程式 GitHub ↗

安裝

桌面版零相依；原始碼/Docker 需 Node ~24、pnpm 10.33.x，另需一個 coding agent CLI。已知地雷：macOS/WSL2 下系統內建的 od（octal-dump）指令會遮蔽 Open Design 的 od CLI，桌面使用者改用 Settings → MCP server 片段；內網 IP（RFC1918/link-local/CGNAT/雲端 metadata）預設會被代理層 SSRF 攔截，需用 OD_ALLOWED_INTERNAL_HOSTS 明確放行。
npm 套件：全域裝一次就能用，也可以用 npx 免安裝直接跑。
桌面應用程式（推薦）：從 open-design.ai 或 GitHub Releases 下載 macOS/Windows/Linux(AppImage) 安裝包WindowsmacOSLinux
od mcp install <agent> # <agent> = claude | codex | reasonix | raven | cursor | copilot | openclaw | antigravity | pi | vibe | hermes | cline | kimi | kiro | trae | opencode
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>
DeepSeek Harness 專用（需先安裝官方 dsh CLI）
od agent setup deepseek-harness
Docker
git clone https://github.com/nexu-io/open-design.git cd open-design/deploy cp .env.example .env echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env docker compose up -d # open http://127.0.0.1:7456
原始碼執行
git clone https://github.com/nexu-io/open-design.git cd open-design corepack enable && pnpm install pnpm tools-dev run web

完整使用教學

01下載安裝桌面應用程式（零設定，自動偵測已安裝的 coding agent）
02開啟應用程式，自動載入 100+ skills、151 套設計系統與渲染模板
03輸入 brief：選產出類型 → 寫描述 → 選設計系統與模型
04看 agent 在預覽視窗即時串流生成
05匯出 HTML / PDF / PPTX / MP4 / ZIP

config

OD_ALLOWED_INTERNAL_HOSTS=<host1>,<host2>,... # 逗号或空白分隔的裸主机名/IP；IPv6 需加方括号如 [fd00::1]

特色功能

·支援 27 個 coding agent（Claude Code / Codex / Cursor / dsh 等）以 BYOK 方式接入
·內建 151 套品牌級設計系統、100+ 功能 skills、277 個外掛
·本機優先，產出真實檔案，支援 HTML/PDF/PPTX/MP4 匯出
