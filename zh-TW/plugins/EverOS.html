EverOS

一份記憶，處處通用。

可攜式記憶層：本地優先、Markdown 原生，跨 agent 應用程式共用同一份自我進化的記憶。
12,081 star v1.2.3 記憶 / 儲存 GitHub ↗

安裝

Python 3.12+；一個 OpenRouter API key。已知地雷：混合檢索需要 embedding provider，一鍵最簡設定只能用 "method": "keyword"；Office 文件擷取依賴系統已安裝 LibreOffice；/api/v1 是遺留別名、將來會移除；缺少選用能力時介面會回傳 HTTP 422；v1.2.3 起背景迴圈失敗會以 SIGTERM 結束行程，需搭配 systemd/Docker/K8s 等外部重啟機制。
Python 套件：用 pip 或 uv 安裝，然後執行它附的指令。
uv pip install everos # or: pip install everos
多模態可選
uv pip install 'everos[multimodal]' # or: pip install 'everos[multimodal]'

完整使用教學

01everos demo 先跑示範（不需要 API key）
02everos init 產生 ~/.everos/everos.toml 與 ~/.everos/ome.toml
03把 OpenRouter API key 填進 everos.toml
04everos server start 啟動服務，用 curl http://127.0.0.1:8000/health 驗證
05透過 /api/v2/memory/add、/api/v2/memory/flush、/api/v2/memory/search 寫入、落地儲存、檢索記憶

config

# everos.toml [llm] model = "openai/gpt-4.1-mini" api_key = "<OPENROUTER_API_KEY>" base_url = "https://openrouter.ai/api/v1"

特色功能

·Markdown 記憶檔案 + Git 版本化，本機 SQLite + LanceDB 索引，無外部資料庫相依
·關鍵字 + 向量混合檢索，支援 user/agent/app/project/session 多維正交檢索
·跨 session 的記憶反思（reflection）自進化；可選用多模態擷取（圖片/PDF/音訊/文件）；生態系含 Claude Code 外掛、EverMem Sync 等
