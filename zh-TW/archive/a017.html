dshplugins.xyz——按「使用意图」分五类的第三方插件地图

不详（非官方社区站） · 入门
生态观察插件推荐选品素材背景知识
原文 ↗
介绍自我定位为「为 Harness 用户绘制地图」的第三方目录站：收录 300+ 插件，按 UI 定制/长期记忆/工具扩展/效率优化/开发支持五大意图分类。核心信息是它的周榜不按 star 而按 README 质量排序，与 GitHub star 榜形成互补视角，两榜交叉可验证推荐名单。对写文章的启发：「按意图分类」的框架比技术分类更适合面向普通读者的推荐文。

要點

·按使用意图分五类的框架，比按技术分类更适合面向普通读者的推荐文结构
·周榜按 README 质量排序不按 star，与 star 榜交叉印证可让推荐名单更有说服力
·目录站的存在本身就是「生态已需要地图」的成熟度证据

關鍵數據

·收录 300+ 插件（站点自述）
·五大意图分类：UI 定制/长期记忆/工具扩展/效率优化/开发支持
·周榜 Top 10 按 README 质量排序
·better-sidebar、dsh-web-ui 在周榜与 star 榜双榜前列

可引用金句

这个站点为 Harness 用户绘制了地图
站点自述定位，介绍目录站时的一句话引用，也隐含「生态已需要地图」的成熟度论点
五大分类：UI 定制（屏幕层面改造）/ 长期记忆（本地磁盘持久化）/ 工具扩展（为模型新增能力）/ 效率优化（降低交互摩擦）/ 开发支持（插件创建脚手架）
现成的读者友好分类框架，可直接借用为推荐文小节结构
特色是不按 star 排——周榜 Top 10 按 README 质量排序，与 GitHub star 榜形成互补视角
解释为何值得交叉引用该站榜单的关键表述
与 GitHub star 榜交叉验证：better-sidebar、dsh-web-ui 两榜皆前列，记忆类插件在两榜都占多席
支撑「记忆类是刚需赛道」和 UI 插件推荐位的双榜互证论据
