LocalLLaMA 发布公告帖：「Deepseek Harness 上线了！」

u/Fun-Doctor6855 · 2026-08-13 · 311 · 入门
生态观察争议短板观点金句背景知识
原文 ↗
DSH 开源当天 r/LocalLLaMA 上的首发公告帖，转发 GitHub 仓库并引用官方「万物皆插件」介绍。评论区吵出三条线：TypeScript 选型之争、星数暴涨真实性存疑、文档全是 LLM 生成的 .md 还带中文无截图。对写文章的启发：这是「五天前发生了什么」的开场素材，三条争议线现成可用，官方「会有破坏兼容性的改动」的警告可提醒读者锁版本。

要點

·DSH 定位是开源 agent harness，架构核心「Everything is a Plugin」，由 Cordis 元框架驱动，目前是 developer preview
·社区首日情绪是好奇大于信任：愿意上手试，但对星数和 LLM 生成文档保持怀疑
·TS 选型正方论点（训练数据多、强类型报错快、适合异步 I/O）在评论区获得压倒性高赞

關鍵數據

·发布当天 311 赞 / 113 评论
·被吐槽的 16~20 个 LLM 生成的 .md 文档
·2500 个 fork 被用作「星数不是刷的」的反证
·TS 选型正方最高赞评论 37 赞

可引用金句

自从 AI agent 出现后，星数就没有意义了。一年前 10 万星意味着世界级基础设施；自从 OpenClaw 之后，随便一个 AI harness 都能轻松破 10 万星。
星数怀疑派的代表金句（21 赞），写「10 万星热度」时必须搭配的平衡视角，避免文章显得无脑吹
我不信全是机器人刷的星，它已经有 2500 个 fork 了。DeepSeek 就是很大，开源这点在欧洲越来越重要。
反驳刷星论的弹药，fork 数是比星数更硬的指标，可与上一条对仗使用
行吧，我可以去读 16~20 个 LLM 生成的 .md 文档（还不算那些中文的）。或者他们也可以在 GitHub README 里放几张截图和基本介绍。
文档吐槽最形象的一条（12 赞），写「上手门槛/避坑」段落时引用，顺便反衬出中文用户读原生中文文档反而有优势
harness 本质上就是网络 I/O、上下文和状态管理。TS 很适合异步事件驱动 I/O，库多社区活跃，还能顺手做个漂亮 UI。
一句话讲清 harness 的技术本质（20 赞），可用于文章「什么是 harness」的通俗化解释
模型在海量 JavaScript 上训练过，强类型语言也更不容易让 bot 写错。虽然我也不爱用这语言，但现在用 bun 分发确实方便。
TS 选型争论正方最高赞（37 赞），解释「为什么 AI 时代的框架都选 TS」的社区共识
