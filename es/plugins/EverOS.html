EverOS

Una sola memoria, útil en todas partes.

Una capa de memoria portátil: local-first, nativa en Markdown, con una sola memoria autoevolutiva compartida entre apps de agentes.
12,081 star v1.2.3 Memoria / almacenamiento GitHub ↗

Instalación

Python 3.12+; una API key de OpenRouter. Problemas conocidos: la búsqueda híbrida necesita un embedding provider, y la configuración mínima de un clic solo admite "method": "keyword"; la ingesta de documentos de Office depende de tener LibreOffice instalado en el sistema; /api/v1 es un alias heredado que se eliminará en el futuro; cuando falta alguna capacidad opcional, la interfaz devuelve HTTP 422; desde la v1.2.3, si falla el bucle en segundo plano el proceso sale con SIGTERM, por lo que hace falta un mecanismo externo de reinicio como systemd/Docker/K8s.
Paquete de Python: instálalo con pip o uv y ejecuta el comando que trae.
uv pip install everos # or: pip install everos
Multimodal opcional
uv pip install 'everos[multimodal]' # or: pip install 'everos[multimodal]'

Tutorial completo

01everos demo para correr primero la demostración (no requiere API key)
02everos init genera ~/.everos/everos.toml y ~/.everos/ome.toml
03Colocar la API key de OpenRouter en everos.toml
04everos server start inicia el servicio; verificar con curl http://127.0.0.1:8000/health
05Escribir, persistir y consultar la memoria mediante /api/v2/memory/add, /api/v2/memory/flush y /api/v2/memory/search

config

# everos.toml [llm] model = "openai/gpt-4.1-mini" api_key = "<OPENROUTER_API_KEY>" base_url = "https://openrouter.ai/api/v1"

Características

·Archivos de memoria en Markdown con versionado en Git, índices locales en SQLite + LanceDB y sin dependencia de bases de datos externas
·Búsqueda híbrida por palabras clave y vectores, con consulta ortogonal en las dimensiones user/agent/app/project/session
·Autoevolución por reflexión (reflection) sobre la memoria entre sesiones; ingesta multimodal opcional (imágenes/PDF/audio/documentos); su ecosistema incluye un plugin para Claude Code, EverMem Sync, entre otros
