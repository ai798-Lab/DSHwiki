smooth-stream

El plugin de salida en streaming hecho por la comunidad china.

Tres niveles de preset ajustables vía cordis.patch.yml; pocas stars, pero mucha conversación en la comunidad china.
21 star Experiencia / salida GitHub

Instalación

El repositorio de código fuente de DeepSeek Harness, o dsh disponible en el PATH; pnpm. Comportamientos y problemas conocidos: si el sistema tiene activado prefers-reduced-motion, el texto se muestra completo de golpe y sin animación; cuando la tasa de cuadros baja de 30fps y la respuesta queda fuera del viewport, la aparición gradual se pausa y continúa al recuperarse; abrir o cerrar manualmente el bloque de razonamiento durante el streaming tiene prioridad sobre la expansión automática; en instalaciones locales de desarrollo con link:/file:, el botón de actualizar queda deshabilitado.
Plugin de dsh: instálalo en tu profile y reinicia dsh web para que tome efecto.
pnpm dsh plugin --profile web add dsh-smooth-stream
Cuando dsh está en el PATH
dsh plugin --profile web add dsh-smooth-stream
Iniciar
pnpm dsh web
Actualizar
dsh plugin --profile web update dsh-smooth-stream
Desinstalar
pnpm dsh plugin --profile web remove dsh-smooth-stream
Otra forma indicada en la publicación de lanzamiento en Reddit (instalación directa con el protocolo github:)
pnpm dsh plugin --profile web add github:Laplace-bit/dsh-smooth-stream

Tutorial completo

01Ejecutar el comando de instalación en el directorio del código fuente de dsh (o desde cualquier ubicación si dsh está en el PATH)
02pnpm dsh web para iniciar la interfaz
03Si en el log del Host aparece "[dsh-smooth-stream] plugin loaded!", la instalación quedó lista
04Ajustar los parámetros en Settings → Plugins → Plugin Configuration

config

在 profile 的 cordis.patch.yml 里改 preset 值：realtime（贴近模型到达速率）/ balanced（默认）/ silky（大缓冲、慢追赶）；另有 maxScrollSpeedPxPerSec（默认 1000）限制滚动速度上限。README 未给出完整 yml 片段原文。

Características

·Muestra el texto de forma gradual al ritmo con el que el modelo emite las palabras, en vez de soltar el bloque entero de golpe, y mantiene el formato Markdown en todo momento
·Las líneas nuevas se deslizan dentro del viewport en lugar de empujar el contenido; si el usuario sube el scroll, se respeta su posición y no se le roba el foco
·Expande automáticamente el proceso de razonamiento (la versión nueva muestra siempre deep diving) y admite degradación por reduced-motion y por baja tasa de cuadros
