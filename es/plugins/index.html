Cómo instalar un plugin de dsh

Un plugin nativo de dsh se instala en tu profile con un comando; reinicia dsh web para que tome efecto:
dsh plugin --profile web add <plugin>

Muchas de las entradas de abajo no son plugins nativos de dsh, sino herramientas independientes: paquetes npm, paquetes de Python, aplicaciones de escritorio o presets que copias a una carpeta. Cada una se instala distinto; abre la página del plugin para ver los comandos completos, separados por sistema operativo.
