OpenViking

La base de datos de contexto para agentes creada por Volcengine.

Gestión unificada de memoria, RAG de conocimiento y skills; su búsqueda en tres niveles L0/L1/L2 ahorra tokens, con el respaldo de una gran tecnológica.
28,891 star v0.4.14 Memoria / almacenamiento GitHub ↗

Instalación

Python 3.10+. Nota de licencia: el proyecto principal usa AGPLv3, mientras que el CLI y los examples usan Apache 2.0.
Paquete de Python: instálalo con pip o uv y ejecuta el comando que trae.
pip install openviking --upgrade
openviking-server init # 交互式配置向导 openviking-server doctor # 校验配置 openviking-server # 启动服务
VikingBot opcional
pip install "openviking[bot]" openviking-server --with-bot ov chat

Tutorial completo

01openviking-server init ejecuta el asistente interactivo (configura providers como Volcengine/OpenAI/Kimi/GLM/Ollama)
02openviking-server doctor valida la configuración
03openviking-server inicia el servicio
04Gestionar y consultar con el CLI ov: ov status, ov add-resource https://github.com/volcengine/OpenViking, ov ls viking://resources/, ov find "what is openviking"
05Integración con agents: compatible con Claude Code, Codex, Cursor, clientes MCP, LangChain/LangGraph, entre otros

config

配置文件位置：~/.openviking/ov.conf（由 init 向导生成）。README 未给出配置文件内容原文片段。

Características

·Carga de contenido en tres niveles —L0 (resumen) / L1 (panorama) / L2 (detalle)— que se expanden a demanda para ahorrar token
·Proceso de búsqueda observable: conserva la traza de navegación por el catálogo, lo que facilita depurar y auditar
·Tras el commit de la sesión, convierte automáticamente las preferencias del usuario y la experiencia del agent en memoria de largo plazo
