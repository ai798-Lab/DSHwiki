colleague-skill

Tu excolega, recontratado en versión digital.

Convierte los documentos, el estilo de código y hasta las muletillas de un veterano en un skill que trabaja como esa persona. La llamada vida digital 1.0, el proyecto más comentado de todo el ecosistema.
23,139 star v0.01（Pre-release，标注 demo） skill / réplica de conocimiento GitHub ↗

Instalación

Python 3.9+; un host compatible (Claude Code / OpenClaw / Codex / DeepSeek Harness, entre otros). Problemas conocidos (según el propio README): la fuente de datos de WeChat es inestable por ahora (se recomienda usar herramientas de código abierto); la versión gratuita de Slack solo permite obtener 90 días de historial; la API de DingTalk no permite descargar mensajes históricos; en conjunto sigue en beta; la calidad del material determina directamente la calidad del Skill.
Un Skill: clona el repositorio en la carpeta skills de tu agent y reinicia.
Instalación en lenguaje natural (díselo a cualquier agent anfitrión)
Install the dot-skill skill for me: https://github.com/titanwings/colleague-skill
Claude Code a nivel de proyecto
mkdir -p .claude/skills git clone https://github.com/titanwings/colleague-skill .claude/skills/create-colleague
Claude Code a nivel global
git clone https://github.com/titanwings/colleague-skill ~/.claude/skills/create-colleague
OpenClaw
git clone https://github.com/titanwings/colleague-skill ~/.openclaw/workspace/skills/create-colleague
Carpetas manuales para otros anfitriones: Codex ~/.codex/skills/dot-skill; DeepSeek Harness ~/.dsh/skills/dot-skill
Dependencias
pip3 install -r requirements.txt

Tutorial completo

01Escribir /create-colleague (o /dot-skill) en el agent host para iniciarlo
02Elegir la familia de roles (colega/relación/celebridad) e ingresar alias, nivel jerárquico en la empresa y etiquetas de personalidad
03Elegir las fuentes de datos (Feishu/DingTalk/Slack/WeChat/correo/PDF, entre otras) para importar el material
04Una vez generado, invocar a este «colega digital» directamente con el comando /{slug}

Características

·Tres familias de roles: colleague (colega) / relationship (relación) / celebrity (celebridad); la línea de celebridades incluye una cadena de herramientas de investigación para procesar subtítulos
·Integración de datos de varias fuentes: Feishu, DingTalk, Slack, WeChat, correo electrónico y PDF
·Los Skill generados admiten control de versiones y reversión, y funcionan en 5 tipos de plataformas host
