modlens

Dale ojos a un modelo de solo texto.

El primer plugin de visión para dsh: pega una imagen y devuelve evidencia estructurada en JSON, con failover entre 10 motores.
2,789 star v3.18.3 Visión / multimodal GitHub ↗

Instalación

Una de tres opciones: Claude Code/Codex/OpenCode/Pi ya con sesión iniciada (se reutilizan sus credenciales), una API key gratuita de Gemini (Google AI Studio), o el CLI gratuito de Antigravity. Problemas conocidos: el comando de instalación fija a propósito @3.18.3 en lugar de @latest, porque pnpm 11 retiene las versiones publicadas hace menos de 24 horas; los modelos de visión quedan excluidos automáticamente y la envoltura de visión solo se aplica a los modelos de texto puro; los modelos que no se pueden confirmar se dejan tal cual para conservar su comportamiento nativo con imágenes.
Plugin de dsh: instálalo en tu profile y reinicia dsh web para que tome efecto.
DeepSeek Harness (el número de versión está fijado a propósito, ver problemas conocidos)
npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.18.3
Línea de skills de LIUSTACK
npx -y skills add liustack/vibemaster -g
Instalación en lenguaje natural: envía esta frase a tu IA
Install and configure the modlens skill following https://github.com/liustack/modlens/blob/main/INSTALL.md, then run the health check

Tutorial completo

01Enviar la línea de instalación de INSTALL.md directamente a tu agent para que se instale solo y corra el health check
02Si el health check sale vacío, configurar un motor gratuito (se recomienda una API key de Gemini: 3 minutos y sin tarjeta de crédito)
03Después de instalar, basta con chatear: pegar una imagen o soltar una ruta y preguntar lo que sea; el skill se activa solo (o mediante la entrada «(modlens vision)» del selector de modelos)

config

modlens config set openai.baseUrl https://dashscope.aliyuncs.com/compatible-mode/v1 modlens config set openai.apiKey <key> modlens config set openai.model qwen3-vl-plus # 其他常用项 modlens config set provider <name> modlens config set proxy <url> modlens config set reuse.codex true modlens config set reuse.opencode true modlens config set reuse.pi true modlens config set reuse.grok true

Características

·Cadena de conmutación por error automática con 10 motores de visión (6 providers integrados + 4 CLI de agent locales reutilizables)
·Reutiliza sin configuración las credenciales multimodales existentes: sin hooks, sin wrapper, sin proceso proxy local y sin tocar ninguna configuración del harness
·La herramienta nativa modlens_read_image devuelve un JSON estructurado con la transcripción completa, las regiones del diseño en orden de lectura y la lista de entidades y relaciones
