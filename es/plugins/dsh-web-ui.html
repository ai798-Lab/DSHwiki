dsh-web-ui

Ponle cara a dsh.

El paquete completo de plugins de Web UI: tablero de tareas, grafo de Git, acceso remoto desde el celular y centro de temas. Si quieres interfaz gráfica, instala este.
4,097 star v0.1.20 UI GitHub ↗

Instalación

dsh instalado y con dsh web arrancando correctamente (la vía de instalación por npm no tiene requisitos extra); instalar desde el repositorio requiere Node.js ≥ 22 + pnpm. Problemas conocidos (según el propio README): el umbral release-age de pnpm 11 hace que las versiones de @linxin666/* publicadas hace menos de 10 días se instalen en su versión antigua, y al aplicar una skin aparece ERR_MODULE_NOT_FOUND ... dsh-client-ui-skin-* (excluirlo con la configuración de arriba); las contraseñas y claves SSH se guardan en texto plano en ~/.dsh/dsh-ssh.json (0600), al reconectar se pueden repetir comandos no idempotentes y la salida remota no está enmascarada; Cloudflare quick tunnel y Tailscale Serve no admiten SSE, así que el celular baja automáticamente a polling y los mensajes pueden llegar con unos segundos de retraso; las tareas programadas que se pierden mientras el host está apagado o suspendido simplemente se omiten y no se recuperan.
Plugin de dsh: instálalo en tu profile y reinicia dsh web para que tome efecto.
Paquete completo (recomendado)
dsh plugin --profile web add @linxin666/dsh-web-ui-all
Instalar solo el tema
dsh plugin --profile web add @linxin666/dsh-skins
Instalación individual
dsh plugin --profile web add @linxin666/dsh-liangshen dsh plugin --profile web add @linxin666/dsh-client-ui-task-board dsh plugin --profile web add @linxin666/dsh-ssh dsh plugin --profile web add @linxin666/dsh-tool-describe-image dsh plugin --profile web add @linxin666/dsh-pet dsh plugin --profile web add dsh-better-sidebar
Instalación desde el repositorio (desarrollo/depuración)
git clone https://github.com/zhu1090093659/dsh-web-ui.git cd dsh-web-ui pnpm install pnpm -r build node scripts/link-profile.mjs dsh plugin --profile web add link:$(pwd)/packages/dsh-web-ui-all dsh web
Desinstalar
dsh plugin --profile web remove @linxin666/dsh-web-ui-all

Tutorial completo

01Instalar el paquete agregado @linxin666/dsh-web-ui-all con el comando recomendado
02Reiniciar dsh web: los accesos a cada plugin aparecen en la barra lateral
03Activar o desactivar cada plugin en Settings → Plugin Configuration, o entrar al centro de skins para probar los 11 temas (primero la vista previa, luego aplicar)

config

# 修复 pnpm 11 新版扣发导致的皮肤崩溃：profile 的 pnpm-workspace.yaml 加 minimumReleaseAgeExclude: - '@linxin666/*' # 以及 nodeLinker: hoisted

Características

·Tablero de tareas con programación cron; diagrama de carriles para visualizar las ramas de Git
·Control remoto emparejando el celular por código QR + panel de operaciones SSH; herramienta de comprensión de imágenes conectada a una API de visión
·Mascota de ballena personalizable, conteo de token en tiempo real, 11 skins que se prueban y cambian al instante, y además un agent preset optimizado para DeepSeek V4 Pro
