token-anxiety

Ansiedad por los costos, aliviada al instante.

Calcula el gasto en tiempo real, el comando Explain detalla a dónde va cada token y la tabla de precios se sincroniza con un solo curl.
0 star v0.1 Costos / facturación GitHub ↗

Instalación

El web profile de DeepSeek Harness; Node.js 22+. Limitaciones conocidas (según el propio README): solo contabiliza las tareas de la sesión raíz, y las sesiones de subagent no aparecen en el widget (el projection fold se pliega de forma sincronizada por sesión); Explain es una ruta directa del host y no un turno del agent, así que su análisis no entra en el log de la sesión y se pierde al refrescar la página; la tabla de precios integrada está «embebida y caduca», por lo que hay que sincronizarla a mano.
Plugin de dsh: instálalo en tu profile y reinicia dsh web para que tome efecto.
Desde npm
dsh plugin --profile web add dsh-token-anxiety
Checkout local
dsh plugin --profile web add /path/to/dsh-token-anxiety
npm directo
npm install dsh-token-anxiety npm install dsh-token-anxiety@0.1.0
Sincronizar la lista de precios manualmente
curl -X POST http://127.0.0.1:3080/token-anxiety/pricing-sync -H "Content-Type: application/json" -d '{}'

Tutorial completo

01Tras instalar, reiniciar dsh web y refrescar la página
02Ubicar el widget de costos en la zona de entrada del chat (composer band) y expandirlo con hover o con un clic
03Revisar Overview (estado de precios pico/valle), Tasks (tabla ordenable del costo por tarea) y Explain (análisis de atribución en un clic sobre qué tareas están gastando)
04Cuando la tabla de precios caduque, sincronizarla a mano con la interfaz pricing-sync

config

默认货币 COP/USD/CNY（支持约 40 种，带地区格式化）；语言跟随 harness locale；价格数据经 host 侧 pricing-sync 接口刷新（curl 命令见安装区），重启后覆盖值合并进默认表。README 未给出配置文件片段原文。

Características

·Estado de precios pico/valle en tiempo real (muestra las ventanas peak/valley en la zona horaria local), para ver de un vistazo en qué franja sale más barato correr tareas
·Tabla ordenable con el costo por tarea + atribución con Explain en un clic (qué tareas gastan y por qué)
·Cerca de 40 monedas, temas claro y oscuro, interfaz bilingüe chino-inglés y empaquetado sin dependencias externas
