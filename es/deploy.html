02 / DEPLOY

Puesta en marcha

De cero a funcionando en cuatro pasos. Todos los comandos verificados uno a uno contra el README oficial.
01

Instala el CLI

Un solo comando con npx y listo; funciona en macOS / Linux / Windows, solo necesitas Node 22.19+.
02

Conecta un modelo

Ingresa tu API key de DeepSeek, o conecta Ollama para usar el modelo que ya corres en local.
03

Arranca

Trabaja directo desde la terminal; si no te gusta la línea de comandos, dsh web abre la interfaz en el navegador.
04

Instala tu primer plugin

Elige uno de la lista destacada e instálalo: a partir de aquí, todo es un plugin.

UPGRADE / UNINSTALL

note
Ni el README, ni apps/cli/README.md, ni la guía de usuario de docs incluyen comandos de actualización o desinstalación (verificado uno por uno: ABSENT); en las discusiones de la comunidad aparece la práctica de limpiar la caché de npx (rm -rf ~/.npm/_npx, ver #49/#897), que es una técnica de diagnóstico y no un procedimiento oficial de actualización

ISSUES

npx no logra instalar | npm tampoco (#1772, resuelto) ↗
Respuesta del propio autor del hilo (2026-08-16): en Debian, no tener instalado build-essential hacía fallar la compilación del módulo nativo node-pty; tras instalar build-essential con apt, la instalación funcionó
No se puede instalar en ArchLinux (#49, 18 comentarios) ↗
Soluciones más votadas: ① instalar las herramientas de compilación con pacman -Syu base-devel; ② cambiar a Bun: bun add --global @deepseek-ai/dsh (node-pty está en la lista blanca de Bun); ③ si se insiste con npm, limpiar la caché y permitir los scripts de compilación: rm -rf ~/.npm/_npx && npx --allow-scripts=node-pty @deepseek-ai/dsh@0.1.0-rc.6 web; otra alternativa: npm config set allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs --location=user
La instalación por línea de comandos no funciona (#897, 10 comentarios) ↗
Diagnóstico de la comunidad: el g++ 9.4.0 que trae el sistema no admite -std=gnu++20 (hace falta GCC 10+); solución: limpiar primero la caché de npx y luego CC=gcc-11 CXX=g++-11 npm install -g @deepseek-ai/dsh, seguido de dsh web
Tras la instalación global con npm, dsh web no arranca: falta pty.node, el módulo nativo de node-pty (#1219) ↗
Causa raíz: node-pty v1.1.0 no trae binarios precompilados para Linux x64 (Node 24/ABI 137) y el script de instalación de npm falla en silencio; solución manual: entrar al directorio de node-pty y ejecutar npx node-gyp rebuild para generar el pty.node faltante; el hilo no tiene respuesta oficial (0 respuestas)
Error Ignored build scripts al instalar plugins con dsh (#2230) ↗
No se obtuvieron los detalles de la solución (1 comentario, sin verificación a fondo); el síntoma se relaciona con la política de seguridad de pnpm que ignora por defecto los scripts de compilación de las dependencias, y puede cruzarse con la solución allow-scripts de #49; esta solución queda pendiente de completar
