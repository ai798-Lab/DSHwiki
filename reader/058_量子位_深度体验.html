中文摘要

这是中文圈质量最高的深度实测文，对「插件推荐」文章价值最大。核心比喻：dsh 是「Agent 时代的安卓」——对比 Codex 的 iPhone 式封闭，dsh 允许你自定义整个 Agent 运行时，是「彻头彻尾为『自进化』和『DIY』而生的马鞍」。文章披露了两组关键数字：官方已内置 100 多个插件、Plugin Store（插件商店）入口已预留；并点名了一批官方内置 Skills 和社区趣味插件。实测部分用 V4 Flash 同题对比 Codex：简单任务打平，复杂长程任务（3D 建模、FPS 游戏）dsh 明显更强，社区记录的最长连续运行时间达 10 小时。文章还记录了 8 月 17 日 API 涨价（尤其缓存）这一背景——标题的「原谅涨价」即由此而来。

原文要点/摘录

  • 定性金句：「这简直是套彻头彻尾为『自进化』和『DIY』而生的马鞍」「普通用户也能参与 AI 的自进化」。
  • 官方内置 Skills（点名）：
    • dsh-code-review —— PR 审查
    • dsh-find-simplifications —— 代码简化建议
    • dsh-doc-standards —— 文档规范审查
    • dsh-prose-standard —— 全仓库文字品控
  • 生态数字：官方内置 100+ 插件，Plugin Store 已预留；社区插件已出现「大鲸鱼 TUI」「QQ 风皮肤」「自定义 emoji」等。
  • 四类 Agent 预设：标准 / PTC（含 Code Mode SDK）/ 极简（仅 bash+编辑器）/ 创造（插件实验）。
  • 特色功能：轨迹（Trajectory）事件级记录回放；未开计划模式也会主动提问澄清需求；Token 统计显示缓存命中率可达 99%+。
  • 实测对比（V4 Flash，同题跑 Codex 与 dsh）：鹈鹕骑自行车 SVG 打平；猪八戒 3D 白模 dsh 多轮返工 20 分钟、效果显著更好；FPS 游戏 dsh 自主补齐下蹲/换弹/瞄准/NPC，「啥 prompt 没给」。
  • 结论句：「DSH 驾驭下，模型的长程任务能力会强非常非常多」；社区最长运行记录 10 小时。
  • 短板：右侧栏缺文件预览/浏览器（Codex 更完整）；V4 多模态弱（「V4 是个瞎子」）；8 月 17 日 API 涨价、缓存涨幅大。

素材价值点

  1. 「dsh-code-review 等四个官方 Skills + 100+ 内置插件 + Plugin Store」是插件推荐文章的直接选品来源，必用。
  2. 「Agent 时代的安卓 vs Codex 的 iPhone」比喻可借用（注明出处）来定调全文。
  3. 短板清单（无侧栏预览、V4 看不了图）恰好对应社区插件的补位方向（better-sidebar、ModLens 等），可以做成「痛点→插件」的推荐逻辑线。
