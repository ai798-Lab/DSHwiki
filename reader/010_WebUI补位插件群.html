中文摘要

围绕官方 Web UI 的「补位插件」是生态里最热闹的赛道，三个代表：dsh-web-ui（4,097 star）是插件合集，一口气提供任务看板、Git 提交图、右侧面板、手机远程 UI、桌面宠物、实时 token 统计和皮肤中心——相当于给官方素颜界面上了一整套妆。DSH-better-sidebar（1,944 star）走「底座」路线：做一个开放侧边栏框架，内置文件渲染编辑/终端/Git/子代理页面，并允许第三方插件注册自己的侧边栏页——插件之上再长插件，是「一切皆插件」的二阶玩法。dsh-TUI（1,812 star）满足终端党：Claude Code 风格的 TUI，鲸鱼顶栏、实时状态、流式思考、双击 Esc 回滚、上下文进度+TPS 显示，npm 一键装，还被 DSH 官方公众号收录过（README 自述）。第三方目录站 dshplugins.xyz 的周榜 Top 2 正是 better-sidebar 和 dsh-web-ui，热度有交叉验证。

原文要点/摘录

  • dsh-web-ui 仓库描述："task board, git graph, right-side panel, remote mobile UI, pet, live token stats, and skin center"
  • DSH-better-sidebar："开放的侧边栏底座，支持三方拓展注册新侧边栏页面。内置文件渲染编辑/终端/Git/子代理页面"；目录站补充：VSCode 式右侧栏，按会话隔离，暴露 service 供其他插件注册标签页和文件查看器
  • dsh-TUI："DSH 官方公众号收录的 TUI 补位插件：Claude Code 风，鲸鱼顶栏/实时状态/流式思考/双击 Esc 回滚/上下文进度+TPS。npm 一键装"
  • 同赛道还有：dsh-cc-tui（Ink 移植版 Claude Code 风 TUI）、dsh-chat-width（消息宽度调节）、dsh-custom-css、dsh-deeplink 等（来自 deepseek-code.com 目录）

素材价值点

  1. 推荐榜「界面改造」小节的三件套，覆盖美化党/效率党/终端党三种人群
  2. better-sidebar 的「插件之上长插件」是解释 dsh 架构优势的最佳实例
  3. dsh-TUI 被官方公众号收录，可作为「官方在主动扶持社区插件」的证据（注：此说法来自其 README 自述，未独立核实）
