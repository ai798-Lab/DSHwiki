dsh-token-anxiety：给「token 焦虑症」做的成本透视插件（附省钱结论）

u/Snoo_57113 · 2026-08-15 · 11 · 入门
插件推荐社区实测选品素材数据实证
原文 ↗ MD →
开发者自嘲式命名的成本插件 dsh-token-anxiety：显示每任务成本、峰谷时段、涨价后同任务价格，能定位哪些任务在烧钱。 比插件更值钱的是作者的数据结论：开放式问题、打错字、prompt 不具体、工具调用 bug 四类占 50% 以上 token 浪费。 一行命令安装甚至可以让 agent 自己克隆装好，和 deepseek-peak 一起构成最先繁荣的成本管理插件类目。

要点

·dsh-token-anxiety（GitHub: mov-eax-eax/dsh-token-anxiety）是「成本可视化」类目代表作，能看单条 prompt 成本和涨价后价格
·四大 token 浪费源：开放式研究问题、打错字、prompt 不具体、工具调用 bug，合计占 50% 以上
·作者三条实操建议：PRO 只留最难问题、其余全用 flash max、没有严格控制就别用 subagents

关键数据

·四类低级浪费占 50%+ 的 token 消耗
·峰谷时段差价巨大（插件专门做了峰谷对比）
·一行命令安装：dsh plugin --profile web add
·11 赞 / 0 评论的新插件发布帖
