Hugging Face 工程师 elie：DSH 能把 Claude Code 和 Codex 当子 agent 调用

官宣仅 1 小时后，Hugging Face 研究工程师 elie 发布英文圈传播最广的技术解读之一（1.3k 赞）。 核心信息：DSH 是内嵌多个 harness 的 Web UI，可通过 SDK 把 Claude Code 和 Codex 当子 agent 生成调用，mode 本质就是不同 harness。 它直接支撑「DSH 不是又一个 CLI 编码代理，而是能吞下其他家 agent 的容器」这一叙事钩子。

要点

·DSH 可以通过 SDK 把 Claude Code 和 Codex agent 当子 agent 生成（spawn）调用——竞品变成了它的插件
·mode = harness 的设计：code mode（TypeScript 程序化工具调用）、bash+edit 等模式本质是不同 harness
·Hugging Face 工程师的正面背书，是大 V 视角评价的高热度样本

关键数据
