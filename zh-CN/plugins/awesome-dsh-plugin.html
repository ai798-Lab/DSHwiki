awesome-dsh-plugin

找插件，从这里开始。

人工核验源码的插件精选目录，约 800+ 插件 20 个类目，配套插件市场 dshmarket。
7,572 star 目录 / 清单 GitHub ↗

安装

DeepSeek Harness 本体（插件经 dsh plugin add 安装）。收录标准原文："An entry is added when the plugin installs with dsh plugin add, does what its one-line description says, sits in the right category, and is maintained. Every submission is checked against its own source before merging."
dsh 插件：装进 profile 后重启 dsh web 才生效。
列表中的插件统一用
dsh plugin add <插件名>
配套插件市场（应用内浏览+一键安装/升级）
dsh plugin --profile web add dshmarket
找插件助手
dsh plugin --profile web add dsh-find-plugin

完整使用教程

01打开仓库 README 按 20 个类目浏览（UI 增强/用量计费/主题/模型/记忆/视觉/语音/工作流/安全等）
02选中插件后用 dsh plugin add 安装（每个插件都声明 dsh.bundle manifest）
03或先装 dshmarket，在 dsh 应用内浏览器里一键安装/升级插件、切换主题
04想投稿：提 PR，按 contributing.md 的审核清单走

特色功能

·约 800+ 插件、20 个类目全景收录（UI/计费/主题/模型/会话/记忆/工具/视觉/语音/skills/安全/远程等）
·收录前逐条对照源码人工核验；仓库消失、停止维护或插件损坏会被移除（收录非永久）
·配套 dshmarket 插件市场与 dsh-find-plugin 助手，构成插件分发入口
