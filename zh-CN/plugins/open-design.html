open-design

把 dsh 当你的设计引擎。

开源版 Claude Design，本地优先桌面应用。接上 dsh 之后文字改稿实时出图，是生态里最大的项目。
88,304 star open-design-v0.19.2 设计 / 桌面应用 GitHub ↗

安装

桌面版零依赖；源码/Docker 需 Node ~24、pnpm 10.33.x，另需一个 coding agent CLI。已知坑：macOS/WSL2 下系统自带 od（octal-dump）命令会遮蔽 Open Design 的 od CLI，桌面用户改用 Settings → MCP server 片段；内网 IP（RFC1918/link-local/CGNAT/云 metadata）默认被代理层 SSRF 拦截，需用 OD_ALLOWED_INTERNAL_HOSTS 显式放行。
npm 包：全局装一次就能用，也可以用 npx 免安装直接跑。
桌面应用（推荐）：从 open-design.ai 或 GitHub Releases 下载 macOS/Windows/Linux(AppImage) 安装包WindowsmacOSLinux
od mcp install <agent> # <agent> = claude | codex | reasonix | raven | cursor | copilot | openclaw | antigravity | pi | vibe | hermes | cline | kimi | kiro | trae | opencode
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>
DeepSeek Harness 专用（需先装官方 dsh CLI）
od agent setup deepseek-harness
Docker
git clone https://github.com/nexu-io/open-design.git cd open-design/deploy cp .env.example .env echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env docker compose up -d # open http://127.0.0.1:7456
源码运行
git clone https://github.com/nexu-io/open-design.git cd open-design corepack enable && pnpm install pnpm tools-dev run web

完整使用教程

01下载安装桌面应用（零配置，自动探测已装的 coding agent）
02打开应用，自动加载 100+ skills、151 套设计系统与渲染模板
03输入 brief：选产物类型 → 写描述 → 选设计系统和模型
04看 agent 在预览窗实时流式生成
05导出 HTML / PDF / PPTX / MP4 / ZIP

config

OD_ALLOWED_INTERNAL_HOSTS=<host1>,<host2>,... # 逗号或空白分隔的裸主机名/IP；IPv6 需加方括号如 [fd00::1]

特色功能

·支持 27 个 coding agent（Claude Code / Codex / Cursor / dsh 等）BYOK 接入
·内置 151 套品牌级设计系统、100+ 功能 skills、277 个插件
·本地优先，产出真实文件，支持 HTML/PDF/PPTX/MP4 导出
