EchoBird

一键安装与模型切换器。

统一管理 Claude Code、Codex、dsh 等 CLI 的安装与切换——非程序员上手首选。
3,063 star v5.6.5 工具 / 安装器 GitHub ↗

安装

Windows / macOS / Linux（x64+arm64），Tauri + Rust 构建。许可注意：v5.0.0+ 为 MIT，更早版本仍是 AGPL-3.0-or-later；有商标/商业外观（trade dress）政策，二次分发注意。
桌面应用：从官网或 GitHub Releases 下载对应系统的安装包。

macOS / LinuxmacOSLinux
curl -fsSL https://echobird.ai/install.sh | sh
手动下载WindowsmacOSLinux
https://github.com/edison7009/EchoBird/releases/latest（Windows x64 / macOS arm64 / Linux x64+arm64，deb 和 fedora 格式）

完整使用教程

01跑对应平台的一行安装脚本（或从 releases 手动下载安装包）
02打开 EchoBird，在工具列表里一键安装目标 CLI（含 DeepSeek Harness：一键安装+模型切换+启动，后台服务+浏览器 UI）
03在 Model Nexus 统一配置模型（OpenAI/Anthropic/本地 LLM/API 路由器），切换时自动改写各工具原生配置文件
04需要本地模型时用内置 vLLM/SGLang/llama.cpp 运行时

特色功能

·Model Nexus 统一模型配置中枢：一处配置，改写 20+ 工具的原生配置文件完成切换
·DeepSeek Harness 一键安装+模型切换+启动（后台服务 + 浏览器 UI），v5.6.5 新增
·内置本地 LLM 运行时（vLLM/SGLang/llama.cpp）+ AI 驱动的安装修复 Agent
