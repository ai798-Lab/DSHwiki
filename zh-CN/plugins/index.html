怎么装一个 dsh 插件

dsh 原生插件是一行命令装进 profile，装完重启 dsh web 才生效：
dsh plugin --profile web add <plugin>
复制
下面清单里不少项目并不是 dsh 原生插件，而是独立工具：npm 包、Python 包、桌面应用，或者要复制到目录里的 preset。装法各不相同——点进每个插件页有按系统分好的完整命令。
