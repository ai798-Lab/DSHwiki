colleague-skill

离职同事，数字返聘。

把前辈的文档、代码风格和口头禅做成“会像 TA 一样干活”的 Skill——所谓数字生命 1.0，全生态话题度最高的项目。
23,139 star v0.01（Pre-release，标注 demo） skill / 知识复刻 GitHub ↗

安装

Python 3.9+；一个兼容宿主（Claude Code / OpenClaw / Codex / DeepSeek Harness 等）。已知坑（README 自述）：微信数据源目前不稳定（建议用开源工具）；Slack 免费版只能取 90 天记录；钉钉 API 不支持拉历史消息；整体仍是 beta；素材质量直接决定 Skill 质量。
Skill：把仓库克隆到宿主 agent 的 skills 目录，重启后即可调用。
自然语言安装（对任意宿主 agent 说）
Install the dot-skill skill for me: https://github.com/titanwings/colleague-skill
Claude Code 项目级
mkdir -p .claude/skills git clone https://github.com/titanwings/colleague-skill .claude/skills/create-colleague
Claude Code 全局
git clone https://github.com/titanwings/colleague-skill ~/.claude/skills/create-colleague
OpenClaw
git clone https://github.com/titanwings/colleague-skill ~/.openclaw/workspace/skills/create-colleague
其他宿主手动目录：Codex ~/.codex/skills/dot-skill；DeepSeek Harness ~/.dsh/skills/dot-skill
依赖
pip3 install -r requirements.txt

完整使用教程

01在宿主 agent 里输入 /create-colleague（或 /dot-skill）启动
02选角色族（同事/关系/名人），输入别名、公司层级、性格标签
03选择数据源（飞书/钉钉/Slack/微信/邮件/PDF 等）导入资料
04生成后用 /{slug} 命令直接调用这个“数字同事”

特色功能

·三大角色族：colleague（同事）/ relationship（关系）/ celebrity（名人），名人线配字幕处理研究工具链
·多源数据整合：飞书、钉钉、Slack、微信、邮件、PDF
·生成的 Skill 支持版本控制与回滚，跨 5 类宿主平台通用
