MindStudio：什么是 DeepSeek Harness？插件化编码 agent 解读 + 实测

Luis Chavez-Mattos（Director of Product） · 2026-08-14 · 进阶
社区实测生态观察数据实证案例演示选品素材
原文 ↗
AI 产品公司 MindStudio 产品总监的解读+实测，带两个独家信息点。 其一是真实成本数据：做 ISS 追踪应用 35 分钟耗约 2000 万 token 但缓存命中率 100%，花费可控；其二是验证了可把 Claude Code、Codex 当「子 agent 插件」接进来由 DeepSeek 指挥。 对写文章的启发：「让 Claude Code 给 DeepSeek 打工」是天然爆点段落，成本数据填「用得起吗」小节的空。

要点

·实证了 dsh 最有话题性的能力：竞争对手 Claude Code/Codex 可作为插件式子 agent 被 DeepSeek 编排
·为数不多的真实成本参照：35 分钟约 2000 万 token，缓存命中率 100%，实际花费可控
·作者建议日常编码任务用便宜的 Flash 而非 Pro，推理强度可调

主要な数字

·ISS 追踪应用实测：约 35 分钟、约 2000 万 token、缓存命中率 100%
·MIT 协议 + YAML 配置即可接入任意模型服务商
·发布次日（2026-08-14）即有企业产品总监完成完整应用实测
