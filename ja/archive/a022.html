要点

·DSH 发布的大环境复杂：正值 V4 Pro 口碑争议 + API 涨价，社区情绪一半拥护开源一半不满涨价
·u/PaluMacil 的评论给出社区视角的 harness 定义：围绕模型的一套工具和机制，让它能以特定方式行动
·自托管派晒出真实数据：2×DGX Spark 256GB 跑出 50 t/s、100 万上下文，但并发 3~4 人才稳

主要な数字

引用できる一節

harness 这个词可以简单理解为：围绕模型的一套工具和机制，让它能以特定方式行动。对写代码来说，它需要能读写文件、执行命令的工具。
社区视角的 harness 定义，比官方术语好懂，适合放在文章「什么是 harness」的开头做通俗解释
