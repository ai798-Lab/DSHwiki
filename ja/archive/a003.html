官方插件开发教程——一个 apply 函数就是一个插件

deepseek-ai · 2026-08-13 · 149,856 · 进阶
官方机制上手教程背景知识案例演示
原文 ↗
官方「第一个插件」教程门槛极低：一个导出 apply 函数的 TypeScript 模块就是插件，十几行代码跑通 hello world。自动清理和声明依赖两个设计免去大量样板代码，发布链路「写→打包→dsh plugin add→topic 被发现」四步闭环。这条闭环正是生态 5 天冒出几千个插件的机制解释，也回答读者「我也能写吗」。

要点

·最小插件就是一个 apply 函数，十几行代码即可跑通，官方教程自带中文版
·通过 ctx 注册的事件、工具、定时器在插件卸载时全部自动清理，不用手写回收逻辑
·「写→装→被发现」的发布闭环（npm 包 + dsh plugin add + dsh-plugin topic）是生态快速膨胀的机制基础

主要な数字
