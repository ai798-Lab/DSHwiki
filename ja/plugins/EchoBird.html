EchoBird

ワンクリックのインストーラー兼モデルスイッチャー。

Claude Code、Codex、dsh など CLI のインストールと切り替えを一元管理——非エンジニアが最初に入れるならこれ。
3,063 star v5.6.5 ツール / インストーラー GitHub ↗

インストール

Windows / macOS / Linux（x64+arm64）、Tauri + Rust でビルド。ライセンス注意：v5.0.0+ は MIT、それ以前のバージョンは AGPL-3.0-or-later のまま。商標/トレードドレス（trade dress）のポリシーがあるため、再配布時は注意。

完全チュートリアル

01各プラットフォーム向けの 1 行インストールスクリプトを実行する（または releases からインストーラーを手動でダウンロード）
02EchoBird を開き、ツール一覧から目的の CLI をワンクリックでインストールする（DeepSeek Harness も対象：ワンクリックインストール + モデル切り替え + 起動、バックグラウンドサービス + ブラウザ UI）
03Model Nexus でモデルを一元的に設定する（OpenAI/Anthropic/ローカル LLM/API ルーター）。切り替え時に各ツールのネイティブ設定ファイルが自動で書き換えられる
04ローカルモデルが必要な場合は内蔵の vLLM/SGLang/llama.cpp ランタイムを使う

特徴

·Model Nexus によるモデル設定の統合ハブ：1 か所で設定すれば、20+ のツールのネイティブ設定ファイルを書き換えて切り替えが完了する
·DeepSeek Harness のワンクリックインストール + モデル切り替え + 起動（バックグラウンドサービス + ブラウザ UI）。v5.6.5 で追加
·ローカル LLM ランタイム（vLLM/SGLang/llama.cpp）を内蔵 + AI 駆動のインストール修復 Agent
