colleague-skill

退職した同僚を、デジタル再雇用。

先輩のドキュメント、コードスタイル、口ぐせを取り込んで「その人のように働く」Skill を作る——いわばデジタル生命 1.0。エコシステム全体で最も話題を集めたプロジェクト。
23,139 star v0.01（Pre-release，标注 demo） skill / ナレッジ複製 GitHub ↗

インストール

Python 3.9+、および対応ホストが 1 つ（Claude Code / OpenClaw / Codex / DeepSeek Harness など）。既知の落とし穴（README の自己申告）：微信（WeChat）のデータソースは現状不安定（オープンソースのツールを使うことを推奨）。Slack の無料版は 90 日分の履歴しか取得できない。钉钉（DingTalk）の API は過去メッセージの取得に非対応。全体としてまだ beta。素材の質がそのまま Skill の質を決める。
Skill：ホスト agent の skills フォルダにクローンして再起動します。
自然言語でインストール（任意のホスト agent に伝える）
Install the dot-skill skill for me: https://github.com/titanwings/colleague-skill
Claude Code プロジェクト単位
mkdir -p .claude/skills git clone https://github.com/titanwings/colleague-skill .claude/skills/create-colleague
Claude Code グローバル
git clone https://github.com/titanwings/colleague-skill ~/.claude/skills/create-colleague
OpenClaw
git clone https://github.com/titanwings/colleague-skill ~/.openclaw/workspace/skills/create-colleague
他ホストの手動ディレクトリ：Codex ~/.codex/skills/dot-skill；DeepSeek Harness ~/.dsh/skills/dot-skill
依存関係
pip3 install -r requirements.txt

完全チュートリアル

01ホストの agent で /create-colleague（または /dot-skill）を入力して起動する
02ロール系統（同僚/関係/著名人）を選び、別名、社内の職位レベル、性格タグを入力する
03データソース（飞书/钉钉/Slack/微信/メール/PDF など）を選んで資料をインポートする
04生成後は /{slug} コマンドでこの「デジタル同僚」を直接呼び出す

特徴

·3 つのロール系統：colleague（同僚）/ relationship（関係）/ celebrity（著名人）。著名人系には字幕処理のリサーチ用ツールチェーンが付属
·複数ソースのデータ統合：飞书（Feishu）、钉钉（DingTalk）、Slack、微信（WeChat）、メール、PDF
·生成された Skill はバージョン管理とロールバックに対応し、5 種類のホストプラットフォームで共通に使える
