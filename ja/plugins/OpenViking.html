OpenViking

Volcengine(火山引擎)発、Agent 向けコンテキストデータベース。

記憶、知識 RAG、Skills を一元管理。L0/L1/L2 の 3 層検索で token を節約、大手のお墨付き。
28,891 star v0.4.14 メモリ / ストレージ GitHub ↗

インストール

Python 3.10+。ライセンス注意：本体は AGPLv3、CLI と examples は Apache 2.0。
Python パッケージ：pip か uv で入れて、付属のコマンドを実行します。
pip install openviking --upgrade
openviking-server init # 交互式配置向导 openviking-server doctor # 校验配置 openviking-server # 启动服务
VikingBot（任意）
pip install "openviking[bot]" openviking-server --with-bot ov chat

完全チュートリアル

01openviking-server init で対話式ウィザードを実行する（Volcengine/OpenAI/Kimi/GLM/Ollama などの provider を設定）
02openviking-server doctor で設定を検証する
03openviking-server でサービスを起動する
04ov CLI で管理と検索を行う：ov status、ov add-resource https://github.com/volcengine/OpenViking、ov ls viking://resources/、ov find "what is openviking"
05agent に接続する：Claude Code、Codex、Cursor、MCP クライアント、LangChain/LangGraph などに対応

config

配置文件位置：~/.openviking/ov.conf（由 init 向导生成）。README 未给出配置文件内容原文片段。

特徴

·L0（要約）/L1（概要）/L2（詳細）の 3 段階でコンテンツを階層読み込みし、必要な分だけ展開して token を節約
·検索プロセスを可観測に：カタログの閲覧履歴を残すため、デバッグと監査がしやすい
·セッションのコミット後、ユーザーの嗜好と agent の経験を自動的に長期メモリとして蓄積
