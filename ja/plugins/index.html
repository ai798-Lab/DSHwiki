DSH プラグイン

入れる価値のあるプラグイン 12 個。それぞれにインストールコマンド、使い方、リアルな評判を掲載。

dsh プラグインの入れ方

dsh のネイティブプラグインはコマンド一行で profile に入ります。反映には dsh web の再起動が必要です：
dsh plugin --profile web add <plugin>
