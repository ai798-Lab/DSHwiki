token-anxiety

コスト不安、その場で解消。

リアルタイムでコストを計算。Explain コマンドが token の使い道を 1 件ずつ説明し、価格表は curl 1 本で同期できる。
0 star v0.1 コスト / 課金 GitHub ↗

インストール

DeepSeek Harness の web profile、Node.js 22+。既知の制限（README の自己申告）：集計するのはルートセッションのタスクのみで、subagent のセッションは widget に出ない（projection fold はセッション単位で同期的に畳み込まれる）。Explain は host の直結ルートであり agent のターンではないため、分析結果はセッションログに残らず、ページを更新すると消える。内蔵の価格表は「埋め込みであり、いずれ古くなる」ため、手動での同期が必要。
dsh プラグイン：profile に入れて dsh web を再起動すると有効になります。
npm から
dsh plugin --profile web add dsh-token-anxiety
ローカルチェックアウト
dsh plugin --profile web add /path/to/dsh-token-anxiety
npm を直接使用
npm install dsh-token-anxiety npm install dsh-token-anxiety@0.1.0
価格表を手動で同期
curl -X POST http://127.0.0.1:3080/token-anxiety/pricing-sync -H "Content-Type: application/json" -d '{}'

完全チュートリアル

01インストール後に dsh web を再起動し、ページを更新する
02チャットの入力エリア（composer band）でコスト widget を見つけ、hover するかクリックして展開する
03Overview（ピーク/オフピーク料金の状態）、Tasks（ソート可能なタスク別コスト表）、Explain（どのタスクがコストを食っているかをワンクリックで要因分析）を見る
04価格表が古くなったら pricing-sync のエンドポイントで手動同期する

config

默认货币 COP/USD/CNY（支持约 40 种，带地区格式化）；语言跟随 harness locale；价格数据经 host 侧 pricing-sync 接口刷新（curl 命令见安装区），重启后覆盖值合并进默认表。README 未给出配置文件片段原文。

特徴

·ピーク/オフピーク料金の状態をリアルタイム表示（ローカルのタイムゾーンで peak/valley の時間帯を表示）。どの時間帯にタスクを流すと安いかが一目で分かる
·タスクごとのコストをソート可能な表で表示 + ワンクリックの Explain による要因分析（どのタスクがコストを食っているか、その理由）
·約 40 種類の通貨、ライト/ダークテーマ、中国語と英語の二言語に対応。外部依存ゼロでバンドル
