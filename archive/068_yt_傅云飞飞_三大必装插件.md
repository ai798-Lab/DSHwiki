## 原文要点/摘录

三大必装插件（图文实录）：
1. **dsh-at-file**（@ 引用文件）：dsh 默认不能 @ 文件，此插件补上。安装：先 `npm install -g pnpm`，再 `dsh plugin --profile web add https://github.com/omdsh-dev/dsh-at-file/archive/refs/heads/main.tar.gz`；装完需重启 dsh 并新建工作区才生效。
2. **ModLens**（让 DeepSeek 看图）：调用 Gemini API 补视觉能力（AI Studio 免费额度即可）；把安装指令发给 dsh 会自动检测、贴 key、自动测图。缺点：图片不能粘贴进对话框，只能给路径或 URL。
3. **DSH-better-sidebar**（侧边栏工作台）：文件目录 + 代码预览 + 命令窗口。安装：`dsh plugin --profile web add dsh-better-sidebar@latest`；GitHub 上的 install.ps1 有兼容 bug，报 ERR_PNPM_IGNORED_BUILDS 时改 `.dsh\profiles\web\pnpm-workspace.yaml` 中 node-pty/protobufjs 为 true 再重跑。

避坑清单（图文实录）：Node 装 22 LTS 别装 24（部分插件不兼容）；用 npm 全局安装别用 npx（npx 不注册 dsh 命令，插件会报 CommandNotFoundException）；装插件前先装 pnpm；GitHub 拉取失败（ECONNRESET）用代理/本地 tar.gz/镜像三种兜底；每装一个插件都要重启 dsh；启动 dsh 的终端窗口不能关；换 Node 版本后要重装 dsh。

实测观察：平均每秒 150+ tokens；标准模式日常够用；创造模式=「没有扳手就造一把扳手」（Agent 现场给自己造插件）。
