## 中文摘要
dsh 官方只有本机 Web UI，社区呼声最高的需求之一就是独立客户端（Discussions 置顶热帖 166 赞）。DSH Desktop 是响应最快的答案：与 dsh 开源同日创建仓库，5 天拿下 1.16 万 star。定位是面向 Windows/macOS 的开源桌面客户端，「一键下载，开箱即用」，把官方 Web UI、Host 服务和插件系统装进原生桌面应用。设计上很聪明：官方 Harness 以固定版本原样运行，Desktop 只负责窗口、托盘、终端、更新和工作配置，并通过官方插件机制与 Harness 组合——slogan「万物皆插件，桌面本身也是插件」直接把官方理念用成了产品卖点。README 明确标注「社区维护的开源项目，并非 DeepSeek 官方产品」。中文优先的文档也说明主力用户画像就是国内开发者。

## 原文要点/摘录
- "万物皆「插件」，桌面本身也是「插件」。"
- "官方 Harness 以固定版本原样运行；Desktop 负责窗口、托盘、终端、更新和工作配置，并通过官方插件机制与 Harness 组合。"
- 支持平台：macOS + Windows；MIT 协议；有 Discord 社区
- 同类竞品：bruc3van/dsh-desktop（独立桌面客户端）、omdsh-dev/awesome-deepseek-harness-desktop（Electron 壳）、GCWing/BitFun（Rust 运行时+桌面）——桌面端是插件生态最卷的赛道之一

## 素材价值点
1. 「官方没做的，社区 5 天补齐」是插件生态故事里最有传播力的案例
2. 与 Discussions 热帖（要桌面端/CLI/TUI）形成完美呼应，可串成「需求→插件」叙事线
3. 面向普通用户的推荐榜里，桌面客户端是最实用的第一推荐位
