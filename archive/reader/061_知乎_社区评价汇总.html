中文摘要

知乎上围绕 dsh 形成了两个问题（「如何评价 8 月 13 日发布的 DeepSeek Harness」「如何看待 DeepSeek Harness 发布」）和一批专栏文章，态度光谱比媒体报道宽得多：从「夯爆了」到「初体验，没有惊喜」都有。社区共识的几个信息点：GitHub 24 小时内即突破 39k+ star（后续几日冲到约 15 万）；随框架发布了一篇 82 页学术论文，提出「时空可组合性」编程范式，用数学证明插件为什么能安全热插拔；社区插件已达 695 个且快速增长。冷静派观点值得重视：对非技术主导的传统企业和普通程序员，现阶段建议继续用 Claude Code / Cursor 等成熟产品，别急着趟浑水。注：知乎全站反爬严格，赞数等精确热度未能直抓，以下要点均来自搜索引擎索引摘要，引用前建议人工打开链接核对。

原文要点/摘录

  • 定性：「一切皆插件——模型、工具、会话、沙箱、UI 界面全是插件」，MIT 协议全开源。
  • 数据点（社区口径）：24 小时不到 39k+ star；82 页论文提出「时空可组合性」；创造模式下「智能体可以检查自己的运行环境，在内存里试验插件，然后改造自己」；社区插件 695 个且快速增长。
  • 冷静观点：「对于非技术主导的传统企业或普通程序员，现阶段可能不需要趟这趟浑水，老老实实使用 Claude Code 或 Cursor 等成熟产品能更好保护开发效率。」
