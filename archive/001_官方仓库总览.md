## 中文摘要
DeepSeek Harness（命令行名 `dsh`）是 DeepSeek 官方 2026-08-13 开源的 agent harness（智能体框架），MIT 协议，主语言 TypeScript，目前处于「开发者预览」阶段（官方明说未来会有破坏兼容的改动）。一句话理念：**一切皆插件**——模型适配器、工具、会话存储、UI、甚至 agent 循环本身，全都是可替换的插件。上手极简单：装好 Node.js 后一条命令 `npx @deepseek-ai/dsh web` 就能在本机 127.0.0.1:3080 打开 Web UI。开源 5 天即逼近 15 万 star，仓库自带官方中文 README、企微群和微信公众号入口，对中文社区非常友好。插件生态靠给仓库打 GitHub topic `dsh-plugin` 聚合，目前该 topic 下已有 6,716 个仓库。

## 原文要点/摘录
- 仓库描述："DeepSeek Harness: Everything is a Plugin."（一切皆插件）
- 底层框架：由 Cordis 驱动（vendored 进仓库），设计源自论文 _A Programming Paradigm for Spatiotemporal Composability_
- 运行方式：`npx @deepseek-ai/dsh web` 启动 Web UI；也可源码运行（pnpm install → build → `pnpm dsh web`）
- 社区入口：GitHub Discussions 提反馈；插件仓库加 `dsh-plugin` topic 便于被发现；官方企微群 + 入群问卷 + 微信公众号（README 内嵌三个二维码）
- 关键数字（2026-08-18 采集）：star 149,856，fork 15,364，topic `dsh-plugin` 下 6,716 个仓库
- 许可证 MIT；仓库含 README.zh.md、CONTRIBUTING.zh.md 等成套中文文档

## 素材价值点
1. 文章开头的「背景板」素材：时间线（8-13 开源）、star 数、一条命令上手，全是硬数字
