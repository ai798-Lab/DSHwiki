## 中文摘要
Agent 最大的短板是「没有长期记忆」，dsh 生态里两个头部方案都不是为 dsh 而生、但都已接入 dsh-plugin 生态。**OpenViking**（28,891 star）是火山引擎（字节系）开源的「Agent 上下文数据库」，口号是自进化 Context Database：把 Agent 记忆、知识 RAG 和 Skills 统一到一个数据库里管理，AGPLv3 协议，有 Lark/微信/Discord 社区和在线 Demo——这是 dsh-plugin topic 前十里唯一的大厂官方项目，意味着大厂开始把自家基础设施往 dsh 生态里挂。**EverOS**（12,081 star）走轻量路线：「一个便携记忆层服务所有 AI agent」，本地优先、Markdown 原生、用户完全拥有数据，跨应用/工具/工作流自进化——设计理念和内容创作者的本地笔记工作流天然契合。另有 mirage（3,499 star，统一虚拟文件系统）、ContextGate（上下文折叠）等同类项目，记忆/上下文是插件生态公认的刚需赛道。

## 原文要点/摘录
- OpenViking 描述："Self-evolving Context Database for AI Agents. Unify Agent Memory, Knowledge RAG and Skills."（自进化 Agent 上下文数据库：统一记忆、知识 RAG 与 Skills）
- EverOS 描述："One portable memory layer for every AI agent: local-first, Markdown-native, user-owned, and self-evolving across apps, tools, and workflows."
- dshplugins.xyz 周榜里另有 dsh-memory-evolve（跨会话长期记忆+后台自演进）、dsh-mnemon（三层本地记忆架构）两个 dsh 原生记忆插件上榜
- awesome-dsh-plugin 列表单设 Memory 分类

## 素材价值点
1. 推荐榜「记忆」小节的两大主角，一大厂一独立，对比感强
2. 「字节的云也来给 DeepSeek 生态打工」是现成的传播点（注意表述准确：是挂 topic 接入生态）
3. EverOS 的 Markdown 原生记忆与目标读者（内容创作者）的工作流直接相关
