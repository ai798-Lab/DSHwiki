awesome-dsh-plugin

Plugin hunting starts here.

A curated plugin directory with hand-verified source code — roughly 800+ plugins across 20 categories, plus dshmarket, its companion plugin marketplace.
7,572 star Directory / list GitHub ↗

Install

DeepSeek Harness itself (plugins are installed with dsh plugin add). Inclusion criteria, verbatim: "An entry is added when the plugin installs with dsh plugin add, does what its one-line description says, sits in the right category, and is maintained. Every submission is checked against its own source before merging."
A dsh plugin: install it into your profile, then restart dsh web.
All plugins in the list use
dsh plugin add <插件名>
Companion plugin marketplace (in-app browsing + one-click install/upgrade)
dsh plugin --profile web add dshmarket
Plugin finder assistant
dsh plugin --profile web add dsh-find-plugin

Full tutorial

01Open the repo README and browse the 20 categories (UI enhancements/usage billing/themes/models/memory/vision/voice/workflows/security and more)
02Pick a plugin and install it with dsh plugin add (every plugin declares a dsh.bundle manifest)
03Or install dshmarket first and install/upgrade plugins and switch themes with one click from the in-app browser in dsh
04To submit an entry: open a PR and follow the review checklist in contributing.md

Features

·Full coverage of roughly 800+ plugins across 20 categories (UI/billing/themes/models/sessions/memory/tools/vision/voice/skills/security/remote and more)
·Every entry is verified by hand against its source before listing; entries are removed when the repo disappears, maintenance stops, or the plugin breaks, so listing is not permanent
·Paired with the dshmarket plugin marketplace and the dsh-find-plugin helper, forming a plugin distribution entry point
