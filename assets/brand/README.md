# DSH Wiki Logo

## 结论

主标志由两张相连的资料页、一条连续路径和三个插件节点组成：资料页代表 Wiki，连续线代表 Harness，节点代表“可插接、可替换、可继续生长”的插件生态。

风格来自已经实现并验收的情绪陪伴 App 视觉语言：暖纸 `#F5F1E8`、墨黑 `#151515`、辅灰 `#5F5B54`，主体结构清楚，只保留轻微手绘不规则感。

## 使用规则

- 36 px 及以上使用标准标；16–24 px 使用 micro 版。
- 浅色背景用墨黑标准版；近黑背景用反白版。
- 图形四周至少保留一个节点直径的净空。
- 不给图形加渐变、投影、玻璃、3D 或纸张纹理；纸张质感属于 UI 背景，不烘焙进 Logo。
- 不使用 DeepSeek 鲸鱼、鱼尾、水波、DeepSeek 蓝、AI 星芒、脑、电路或机器人，避免混淆官方身份。
