Web UI 补位插件群——看板、侧边栏、TUI，把官方界面改成你想要的样子

zhu1090093659 / omdsh-dev / ccch1mneyyy · 2026-08-07~08-13 · 4,097 · 入门
插件推荐选品素材案例演示
원문 ↗
围绕官方 Web UI 的补位插件是生态最热闹赛道：dsh-web-ui（4,097 star）一口气给素颜界面加看板、Git 图、桌宠、皮肤中心；better-sidebar（1,944 star）做开放侧边栏底座，允许插件之上再长插件；dsh-TUI（1,812 star）给终端党 Claude Code 风体验。三件套正好覆盖美化党、效率党、终端党，是推荐榜「界面改造」小节的现成结构。

핵심

·三件套各占一个人群：dsh-web-ui 管美化增强、better-sidebar 管扩展底座、dsh-TUI 管终端体验
·better-sidebar 的「插件之上长插件」二阶玩法，是解释 dsh 架构优势的最佳实例
·热度有交叉验证：目录站 dshplugins.xyz 周榜 Top 2 正是 better-sidebar 和 dsh-web-ui

핵심 수치

·dsh-web-ui 4,097 star / DSH-better-sidebar 1,944 star / dsh-TUI 1,812 star
·dsh-web-ui 一个合集包含 7 类功能：看板、Git 图、右侧面板、手机远程、桌宠、token 统计、皮肤中心
·目录站 dshplugins.xyz 周榜 Top 2 均出自本组
·三仓库创建于 2026-08-07~08-13 一周内

인용할 문장

相当于给官方素颜界面上了一整套妆
生动比喻，dsh-web-ui 推荐卡的一句话定位，设计师受众秒懂
插件之上再长插件，是「一切皆插件」的二阶玩法
better-sidebar 的核心亮点判断，可回扣文章前面的架构段形成呼应
DSH 官方公众号收录的 TUI 补位插件：Claude Code 风，鲸鱼顶栏/实时状态/流式思考/双击 Esc 回滚/上下文进度+TPS。npm 一键装
dsh-TUI 的功能密度全在这句里，引用时需注明「官方公众号收录」出自其 README 自述、未独立核实
开放的侧边栏底座，支持三方拓展注册新侧边栏页面。内置文件渲染编辑/终端/Git/子代理页面
better-sidebar 仓库描述原文，推荐卡功能清单可直接用
