四种官方运行模式——标准/PTC/极简/创造，官方定义全是中文

deepseek-ai · 2026-08-13 · 149,856 · 进阶
官方机制背景知识观点金句案例演示
원문 ↗
dsh 内置标准、PTC、极简、创造四个 agent preset，官方 preset.yml 的名称和描述直接用中文写。PTC 让模型写 TypeScript 程序合并多步操作省 token，极简只留两个工具，创造模式则用来造新 preset，等于用 agent 造 agent。四种模式本身就是插件化组合，天然可作文章的一个小节结构，每种配一句官方中文描述即可。

핵심

·四种模式各有取向：标准全能、PTC 省 token、极简走「少工具+强模型」、创造模式用 agent 造 agent
·preset 定义文件官方直接用中文写，是「中文开发者是第一目标用户」的罕见实证
·preset 是按 cordis.yml 组合的每会话插件树，四种模式本身就是「一切皆插件」的落地证据

핵심 수치

·内置 4 种运行模式，按 order 1-4 排序
·极简模式只保留 2 个工具（持久 bash + str_replace_editor）
·主仓库 star 149,856

인용할 문장

功能完整的编码 Agent，支持文件编辑、Shell、文件与网页检索、Skills、计划、目标、子代理和工作流。
标准模式官方中文定义原文，模式介绍段直接引用
仅提供持久 bash 与 str_replace_editor 的双工具编码 Agent。

用于创建自定义 Agent preset：具备标准模式的全部能力，并提供运行时检查、插件实验和 preset 创作指导。
创造模式官方定义，「用 agent 造 agent」猎奇段的权威出处
