EchoBird

원클릭 설치와 모델 전환기.

Claude Code, Codex, dsh 같은 CLI의 설치와 전환을 한곳에서 관리해요. 비개발자 입문용으로 첫손에 꼽혀요.
3,063 star v5.6.5 도구 / 인스톨러 GitHub ↗

설치

Windows / macOS / Linux(x64+arm64), Tauri + Rust 빌드. 라이선스 주의: v5.0.0+ 는 MIT이고 그 이전 버전은 여전히 AGPL-3.0-or-later. 상표/트레이드 드레스(trade dress) 정책이 있으므로 재배포 시 주의.
데스크톱 앱: 공식 사이트나 GitHub Releases에서 사용 중인 OS용 설치 파일을 받습니다.

전체 사용 가이드

01플랫폼에 맞는 한 줄 설치 스크립트 실행(또는 releases에서 설치 파일 직접 다운로드)
02EchoBird를 열고 도구 목록에서 원하는 CLI를 원클릭 설치(DeepSeek Harness 포함: 원클릭 설치 + 모델 전환 + 실행, 백그라운드 서비스 + 브라우저 UI)
03Model Nexus에서 모델을 통합 설정(OpenAI/Anthropic/로컬 LLM/API 라우터). 전환하면 각 도구의 네이티브 설정 파일이 자동으로 수정됨
04로컬 모델이 필요하면 기본 탑재된 vLLM/SGLang/llama.cpp 런타임 사용

특징

·Model Nexus 통합 모델 설정 허브: 한 곳에서 설정하면 20개 이상 도구의 네이티브 설정 파일을 고쳐 전환을 끝냄
·DeepSeek Harness 원클릭 설치 + 모델 전환 + 실행(백그라운드 서비스 + 브라우저 UI), v5.6.5에서 추가
·로컬 LLM 런타임 기본 탑재(vLLM/SGLang/llama.cpp) + AI 기반 설치 복구 Agent
