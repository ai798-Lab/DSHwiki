EverOS

하나의 메모리, 어디서든 통용.

휴대용 메모리 레이어예요. 로컬 우선, Markdown 네이티브로, 여러 agent 앱이 스스로 진화하는 메모리 하나를 공유해요.
12,081 star v1.2.3 메모리 / 스토리지 GitHub

설치

Python 3.12+, OpenRouter API key 하나. 알려진 함정: 하이브리드 검색에는 embedding provider가 필요해서 원클릭 최소 구성에서는 "method": "keyword" 만 쓸 수 있음. Office 문서 수집은 시스템에 설치된 LibreOffice에 의존. /api/v1 은 레거시 별칭으로 향후 제거 예정. 선택 기능이 빠져 있으면 API가 HTTP 422를 반환. v1.2.3부터는 백그라운드 루프가 실패하면 SIGTERM으로 프로세스가 종료되므로 systemd/Docker/K8s 같은 외부 재시작 장치가 필요.
Python 패키지: pip 또는 uv로 설치한 뒤 함께 제공되는 명령을 실행합니다.
uv pip install everos # or: pip install everos
멀티모달 선택 사항
uv pip install 'everos[multimodal]' # or: pip install 'everos[multimodal]'

전체 사용 가이드

01everos demo 로 데모 먼저 실행(API key 불필요)
02everos init 으로 ~/.everos/everos.toml 과 ~/.everos/ome.toml 생성
03OpenRouter API key를 everos.toml 에 입력
04everos server start 로 서비스 시작 후 curl http://127.0.0.1:8000/health 로 확인
05/api/v2/memory/add, /api/v2/memory/flush, /api/v2/memory/search 로 메모리를 기록, 저장, 검색

config

# everos.toml [llm] model = "openai/gpt-4.1-mini" api_key = "<OPENROUTER_API_KEY>" base_url = "https://openrouter.ai/api/v1"

특징

·Markdown 메모리 파일 + Git 버전 관리, 로컬 SQLite + LanceDB 인덱스, 외부 데이터베이스 의존 없음
·키워드 + 벡터 하이브리드 검색, user/agent/app/project/session 다차원 직교 검색 지원
·세션 간 메모리 반추(reflection)를 통한 자기 진화. 멀티모달 수집(이미지/PDF/오디오/문서)은 선택 기능. 생태계에는 Claude Code 플러그인, EverMem Sync 등이 포함
