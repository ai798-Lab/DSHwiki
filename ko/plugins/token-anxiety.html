token-anxiety

비용 불안, 그 자리에서 해소.

비용을 실시간으로 계산해요. Explain 명령어가 token이 어디에 쓰였는지 건건이 설명해 주고, 가격표는 curl 한 줄로 동기화돼요.
0 star v0.1 비용 / 과금 GitHub ↗

설치

DeepSeek Harness의 web profile, Node.js 22+. 알려진 제약(README 자체 기재): 루트 세션 작업만 집계하며 subagent 세션은 widget에 나타나지 않음(projection fold가 세션 단위로 접힘). Explain은 host 직결 라우트이고 agent 턴이 아니어서 분석 결과가 세션 로그에 남지 않고 페이지를 새로고침하면 사라짐. 내장 가격표는 「코드에 박혀 있고 시간이 지나면 낡는」 형태라 수동으로 동기화해야 함.
dsh 플러그인: profile에 설치한 뒤 dsh web을 재시작하면 적용됩니다.
npm에서
dsh plugin --profile web add dsh-token-anxiety
로컬 체크아웃
dsh plugin --profile web add /path/to/dsh-token-anxiety
npm 직접 사용
npm install dsh-token-anxiety npm install dsh-token-anxiety@0.1.0
가격표 수동 동기화
curl -X POST http://127.0.0.1:3080/token-anxiety/pricing-sync -H "Content-Type: application/json" -d '{}'

전체 사용 가이드

01설치 후 dsh web 을 재시작하고 페이지 새로고침
02채팅 입력 영역(composer band)에서 비용 widget을 찾아 hover 하거나 클릭해 펼치기
03Overview(피크/오프피크 요금 상태), Tasks(정렬 가능한 작업별 비용 표), Explain(어떤 작업이 돈을 태우는지 원클릭 원인 분석) 확인
04가격표가 낡으면 pricing-sync 인터페이스로 수동 동기화

config

默认货币 COP/USD/CNY（支持约 40 种，带地区格式化）；语言跟随 harness locale；价格数据经 host 侧 pricing-sync 接口刷新（curl 命令见安装区），重启后覆盖值合并进默认表。README 未给出配置文件片段原文。

특징

·실시간 피크/오프피크 요금 상태(로컬 시간대 기준 peak/valley 구간 표시)로 어느 시간대에 작업을 돌려야 싼지 한눈에 확인
·작업별 비용을 정렬 가능한 표로 제공 + 원클릭 Explain 원인 분석(어떤 작업이 돈을 태우는지, 왜 그런지)
·약 40종 통화, 라이트/다크 테마, 중국어·영어 2개 언어, 외부 의존성 없이 패키징

I made a plugin (Token anxiety) for the deepseek harness 0.1 that shows the cost per task, the peak hours and how much a task would cost after the hike... As tips to reduce your bill I found that open research questions, typos, not being specific in the prompts and bugs in toolcalling make up 50%+ of the tokens.
DeepSeek Harness 0.1용 플러그인(Token anxiety)을 만들었어요. 작업별 비용, 피크 시간대, 가격 인상 후 같은 작업이 얼마가 될지를 보여줘요… 요금을 줄이는 팁을 찾아보니, 열린 리서치 질문, 오타, 구체적이지 않은 프롬프트, 도구 호출 버그가 전체 token의 50% 이상을 차지하더라고요.
