open-design

dsh를 당신의 디자인 엔진으로.

오픈소스판 Claude Design이자 로컬 우선 데스크톱 앱이에요. dsh에 연결하면 텍스트로 고치는 대로 실시간으로 결과물이 나와요. 생태계에서 가장 큰 프로젝트예요.
88,304 star open-design-v0.19.2 디자인 / 데스크톱 앱 GitHub ↗

설치

데스크톱 버전은 의존성 없음. 소스/Docker 실행에는 Node ~24, pnpm 10.33.x와 coding agent CLI 하나가 필요. 알려진 함정: macOS/WSL2에서는 시스템 기본 od(octal-dump) 명령이 Open Design의 od CLI를 가리므로 데스크톱 사용자는 Settings → MCP server 스니펫을 사용할 것. 내부망 IP(RFC1918/link-local/CGNAT/클라우드 metadata)는 프록시 계층의 SSRF 차단에 기본으로 걸리므로 OD_ALLOWED_INTERNAL_HOSTS로 명시적으로 허용해야 함.
npm 패키지: 전역으로 한 번 설치하거나 npx로 설치 없이 실행할 수 있습니다.
데스크톱 앱(권장): open-design.ai 또는 GitHub Releases에서 macOS/Windows/Linux(AppImage) 설치 파일 다운로드WindowsmacOSLinux
od mcp install <agent> # <agent> = claude | codex | reasonix | raven | cursor | copilot | openclaw | antigravity | pi | vibe | hermes | cline | kimi | kiro | trae | opencode
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>
DeepSeek Harness 전용(공식 dsh CLI 먼저 설치 필요)
od agent setup deepseek-harness
Docker
git clone https://github.com/nexu-io/open-design.git cd open-design/deploy cp .env.example .env echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env docker compose up -d # open http://127.0.0.1:7456
소스로 실행
git clone https://github.com/nexu-io/open-design.git cd open-design corepack enable && pnpm install pnpm tools-dev run web

전체 사용 가이드

01데스크톱 앱 다운로드 후 설치(설정 불필요, 이미 설치된 coding agent 자동 탐지)
02앱을 열면 100+ skills, 디자인 시스템 151종과 렌더링 템플릿이 자동 로드됨
03brief 입력: 산출물 유형 선택 → 설명 작성 → 디자인 시스템과 모델 선택
04agent가 미리보기 창에서 실시간 스트리밍으로 생성하는 과정 확인
05HTML / PDF / PPTX / MP4 / ZIP 내보내기

config

OD_ALLOWED_INTERNAL_HOSTS=<host1>,<host2>,... # 逗号或空白分隔的裸主机名/IP；IPv6 需加方括号如 [fd00::1]

특징

·coding agent 27종(Claude Code / Codex / Cursor / dsh 등) BYOK 연결 지원
·브랜드급 디자인 시스템 151종, 기능 skills 100+개, 플러그인 277개 기본 탑재
·로컬 우선, 실제 파일로 산출, HTML/PDF/PPTX/MP4 내보내기 지원
