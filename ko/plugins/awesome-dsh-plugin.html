awesome-dsh-plugin

플러그인 찾기는 여기서부터.

소스 코드를 사람이 직접 검증한 추천 플러그인 디렉터리예요. 약 800+개 플러그인을 20개 카테고리로 정리했고, 플러그인 마켓 dshmarket도 함께 운영돼요.
7,572 star 디렉터리 / 리스트 GitHub ↗

설치

DeepSeek Harness 본체(플러그인은 dsh plugin add 로 설치). 수록 기준 원문: "An entry is added when the plugin installs with dsh plugin add, does what its one-line description says, sits in the right category, and is maintained. Every submission is checked against its own source before merging."
dsh 플러그인: profile에 설치한 뒤 dsh web을 재시작하면 적용됩니다.
목록의 플러그인은 공통으로 사용
dsh plugin add <插件名>
전용 플러그인 마켓(앱 내 탐색 + 원클릭 설치/업그레이드)
dsh plugin --profile web add dshmarket
플러그인 찾기 도우미
dsh plugin --profile web add dsh-find-plugin

전체 사용 가이드

01저장소 README를 열어 20개 카테고리별로 훑어보기(UI 확장/사용량 과금/테마/모델/메모리/비전/음성/워크플로/보안 등)
02설치할 플러그인을 고른 뒤 dsh plugin add 로 설치(모든 플러그인이 dsh.bundle manifest를 선언)
03또는 dshmarket 을 먼저 설치해 dsh 앱 내 브라우저에서 플러그인 설치/업그레이드와 테마 전환을 한 번에 처리
04등록 신청은 PR로. contributing.md의 심사 체크리스트를 따를 것

특징

·약 800+ 개 플러그인을 20개 카테고리로 전방위 수록(UI/과금/테마/모델/세션/메모리/도구/비전/음성/skills/보안/원격 등)
·수록 전 항목마다 소스 코드와 대조해 수작업 검증. 저장소가 사라지거나 유지보수가 중단되거나 플러그인이 망가지면 삭제됨(수록은 영구적이지 않음)
·dshmarket 플러그인 마켓과 dsh-find-plugin 도우미가 함께 제공돼 플러그인 배포 입구를 이룸
