smooth-stream

중국어권 커뮤니티가 만든 스트리밍 출력 플러그인.

cordis.patch.yml로 3단계 preset을 조절할 수 있어요. star 수는 많지 않지만 중국어권에서는 꽤 화제예요.
21 star 경험 / 출력 GitHub ↗

설치

DeepSeek Harness 소스 저장소, 또는 PATH에 dsh가 있을 것. pnpm 필요. 알려진 동작/함정: 시스템에서 prefers-reduced-motion이 켜져 있으면 애니메이션 없이 전체 문단이 바로 표시됨. 프레임률이 30fps 아래이고 응답이 뷰포트 밖에 있으면 페이드인이 멈췄다가 복귀 후 이어짐. 스트리밍 중에 사고 블록을 직접 열고 닫으면 자동 펼침보다 우선함. link:/file: 로 로컬 개발 설치한 경우 업데이트 버튼이 비활성화됨.
dsh 플러그인: profile에 설치한 뒤 dsh web을 재시작하면 적용됩니다.
pnpm dsh plugin --profile web add dsh-smooth-stream
dsh가 PATH에 있을 때
dsh plugin --profile web add dsh-smooth-stream
실행
pnpm dsh web
업데이트
dsh plugin --profile web update dsh-smooth-stream
제거
pnpm dsh plugin --profile web remove dsh-smooth-stream
Reddit 공개 게시물의 다른 방식(github: 프로토콜로 직접 설치)
pnpm dsh plugin --profile web add github:Laplace-bit/dsh-smooth-stream

전체 사용 가이드

01dsh 소스 디렉터리에서(또는 dsh가 PATH에 있으면 아무 위치에서나) 설치 명령 실행
02pnpm dsh web 으로 인터페이스 실행
03Host 로그에 "[dsh-smooth-stream] plugin loaded!" 가 뜨면 설치 완료
04Settings → Plugins → Plugin Configuration 에서 파라미터 조정

config

在 profile 的 cordis.patch.yml 里改 preset 值：realtime（贴近模型到达速率）/ balanced（默认）/ silky（大缓冲、慢追赶）；另有 maxScrollSpeedPxPerSec（默认 1000）限制滚动速度上限。README 未给出完整 yml 片段原文。

특징

·모델이 토큰을 뱉는 속도에 맞춰 텍스트를 서서히 표시. 문단이 통째로 튀어나오지 않고 Markdown 서식도 계속 유지
·새 줄이 기존 내용을 밀어내지 않고 뷰포트 안으로 미끄러져 들어옴. 사용자가 위로 스크롤한 상태면 스크롤 위치를 존중하고 포커스를 뺏지 않음
·사고 과정 자동 펼침(신버전은 deep diving을 항상 표시), reduced-motion과 저프레임률 강등도 지원
