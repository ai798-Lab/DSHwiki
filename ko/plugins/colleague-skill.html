colleague-skill

퇴사한 동료, 디지털로 재고용.

선배의 문서, 코드 스타일, 말버릇까지 담아 '그 사람처럼 일하는' Skill로 만들어요. 이른바 디지털 생명 1.0, 생태계 전체에서 화제성 1위 프로젝트예요.
23,139 star v0.01（Pre-release，标注 demo） skill / 지식 복제 GitHub ↗

설치

Python 3.9+, 호환되는 호스트 하나(Claude Code / OpenClaw / Codex / DeepSeek Harness 등). 알려진 함정(README 자체 기재): WeChat 데이터 소스가 현재 불안정(오픈소스 도구 사용 권장). Slack 무료 플랜은 90일치 기록만 가져올 수 있음. DingTalk API는 과거 메시지 조회를 지원하지 않음. 전체적으로 아직 beta. 자료 품질이 Skill 품질을 그대로 좌우함.
Skill: 호스트 agent의 skills 폴더에 클론한 뒤 재시작합니다.
자연어 설치(아무 호스트 agent에게 말하기)
Install the dot-skill skill for me: https://github.com/titanwings/colleague-skill
Claude Code 프로젝트 단위
mkdir -p .claude/skills git clone https://github.com/titanwings/colleague-skill .claude/skills/create-colleague
Claude Code 전역
git clone https://github.com/titanwings/colleague-skill ~/.claude/skills/create-colleague
OpenClaw
git clone https://github.com/titanwings/colleague-skill ~/.openclaw/workspace/skills/create-colleague
다른 호스트 수동 디렉터리: Codex ~/.codex/skills/dot-skill; DeepSeek Harness ~/.dsh/skills/dot-skill
의존성
pip3 install -r requirements.txt

전체 사용 가이드

01호스트 agent에서 /create-colleague(또는 /dot-skill) 입력해 시작
02역할군(동료/관계/유명인)을 고르고 별칭, 회사 직급, 성격 태그 입력
03데이터 소스(Feishu/DingTalk/Slack/WeChat/이메일/PDF 등)를 골라 자료 가져오기
04생성 후 /{slug} 명령으로 이 「디지털 동료」를 바로 호출

특징

·3대 역할군: colleague(동료) / relationship(관계) / celebrity(유명인). 유명인 라인에는 자막 처리 리서치 툴체인이 함께 제공
·다중 소스 데이터 통합: Feishu, DingTalk, Slack, WeChat, 이메일, PDF
·생성된 Skill은 버전 관리와 롤백을 지원하며 5종 호스트 플랫폼에서 공통으로 사용 가능
